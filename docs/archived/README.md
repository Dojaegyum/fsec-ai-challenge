# 아카이브

주제가 **FinAlly(보이스피싱 사후 대응)** 로 확정되면서 역할이 끝난 문서를 모아둔 곳입니다.
지우지 않고 남기는 이유는 결정의 근거 원문이기 때문입니다 — **읽되, 갱신하지 않습니다.**
