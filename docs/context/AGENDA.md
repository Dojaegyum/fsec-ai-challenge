# 2026 금융 AI Challenge — 대회 개요와 일정

> 근거는 둘입니다. [금융보안원 공고문](https://www.fsec.or.kr/bbs/detail?menuNo=66&bbsNo=11997)과
> **데이콘 대회 페이지**(접수·평가·규칙 탭, 2026-09-06 확인). 둘이 다르면 **데이콘 페이지가 실제 접수 규칙**입니다.
> 진행 상황 체크리스트는 여기 두지 않습니다 — 남은 일은 [제출 핸드오프](../plans/09-04-submission-handoff.md),
> 정한 것은 [`decisions/`](../../decisions/)에 있습니다.

## 대회

| 항목 | 내용 |
| --- | --- |
| 주최·주관 | 금융보안원 |
| 후원 | 금융위원회 |
| 공동개최사 | 하나은행 · 신한은행 · 카카오뱅크 · KB증권 · 생명보험협회 |
| 운영 | 데이콘 — **공식 문의는 대회 게시판만** (다른 채널은 답변되지 않을 수 있음) |
| 회차 | 제2회 (2025년 제1회는 951팀 참가, FISCON에서 시상) |
| 성격 | 아이디어 제안이 아니라 **실제 작동하는 웹서비스(MVP)로 구현·검증** |
| 주제 | AI 기반의 금융 현안 해결 아이디어 및 웹서비스 개발 — 금융소비자 특성과 서비스 채널을 고려한 맞춤형 금융 AI 서비스 |
| 주제 자유도 | 예시에 구속되지 않음 — "제시된 예시에 한정되지 않고 주제 범위 내에서 자유롭게 선정" |
| 참가 자격 | 전 국민, 개인 또는 4인 이내 그룹. 동일인의 중복 등록 불가 |
| 부상 | 수상 시 금융보안원 채용 우대 (공고문) |

### 예시 주제 7개 (참고)

1. 창업기업 및 신규 소상공인을 위한 AI 맞춤형 금융 매칭 서비스
2. 국내 체류 외국인 고객의 금융 정착을 돕는 AI Agent
3. **보이스피싱 등 이상금융거래 탐지 시 맞춤형 행동 요령을 제공하는 AI 금융 보안 비서** ← 우리 주제가 닿는 곳 ([ADR-001](../../decisions/001-topic-selection.md))
4. AI와 비정형 데이터 분석을 통한 혁신·벤처기업의 다차원 성장성 평가 및 투자 매칭 플랫폼
5. 청년층 자산 형성 및 고령층·장애인 디지털 격차 해소를 위한 AI 기반 포용적 금융서비스
6. 이상금융거래 및 보험사기 등을 AI로 분석하여 탐지할 수 있는 서비스
7. 프론티어 AI 공격 방어를 위한 대화형 AI 보안 대응 비서

| 수상자 발표 | 10-23(금) (공고문) | |

### 접수 때 지켜야 할 것

- **기획서와 기능 명세서는 PDF 로 냅니다.** 양식은 hwpx 지만 제출 파일은 PDF 입니다. 저장소 최상단의 hwpx 두 개를 한글에서 열어 PDF 로 내보낸 뒤 올립니다.
- **웹서비스 URL은 실행 가능한 링크**여야 하고, 9/7 11:00 ~ 9/11 23:59 동안 살아 있어야 합니다. 주소: https://fin-ally-khaki.vercel.app
- **팀으로 제출하려면 팀장이 대회 페이지에서 「팀으로 전환」을 먼저 완료**해야 합니다(팀빌딩 페이지로 팀을 만든 경우).
- **마감 뒤에는 산출물을 고칠 수 없습니다.** 운영 측 요청 자료 미제출·누락은 결격 사유입니다.
- 제출한 모든 산출물의 책임은 참가자에게 있고, 표절·무단 사용은 심사 제외 또는 수상 취소입니다.
