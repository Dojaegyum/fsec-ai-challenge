## 소스 주소 — 실측 확인 (2026-08-16)

**1. 국가법령정보 Open API**

```
검색  https://www.law.go.kr/DRF/lawSearch.do?OC=<키>&target=law&type=XML&query=<법령명>
본문  https://www.law.go.kr/DRF/lawService.do?OC=<키>&target=law&MST=<일련번호>&type=XML&efYd=<시행일>
이력  https://www.law.go.kr/DRF/lawSearch.do?OC=<키>&target=eflaw&type=XML&query=<법령명>
```

| 확인한 것 | 값 |
| --- | --- |
| 통신사기피해환급법 법령ID | `011359` |
| 조문 수 | 법률 31개 · 시행령 27개 |
| 응답 크기 | 법률 47KB · 시행령 223KB |
| 이력 조회 | 2011년 제정부터 22건 전부 |

**`efYd`로 시행일 기준 본문을 조회할 수 있습니다.** 과거 시점 조문을 그대로 재현할 수 있습니다.

**`<조문시행일자>`가 조문마다 따로 있습니다.** 법령 하나 안에서도 조문별 시행일이 다를 수 있습니다.

**2. 법제처 입법예고 API** — 공공데이터포털 `data.go.kr/data/15090734`

**법령 API만 보면 예정된 개정을 놓칩니다.** 실측에서 법령 이력 22건에 **가상자산 2026-10-01 개정이 없었습니다.** 공포 전이라 안 뜹니다. 우리가 그걸 아는 건 보도자료를 봤기 때문입니다.

**3. 금융위원회 게시판**

| 게시판 | RSS |
| --- | --- |
| 보도자료 | `https://www.fsc.go.kr/about/fsc_bbs_rss/?fid=0111` |
| 보도설명자료 | `…?fid=0112` |
| 공지사항 | `…?fid=0114` |

**RSS는 최근 10건만 주고, 그 10건이 4일치입니다.** 수집이 며칠만 멈춰도 그 사이 게시물이 밀려나 사라집니다.

**그래서 RSS는 감지에만 쓰고 실제 수집은 목록 페이지에서 합니다.** 이전 수집 지점과 겹칠 때까지 쪽을 넘깁니다 → [data-model §12.5](../../spec/backend/08-16-data-model.md)

## 감시되지 않는 층

**「전부 감시한다」고 말할 수 없습니다.**

| 순위 | 내용 | 근거의 출처 | 자동 감시 |
| --- | --- | --- | :---: |
| 3순위 공통 | 112 신고, 명의도용 점검 | 법률 | **가능** |
| 2순위 유형 기본 | 3영업일·14일 기한 | **시행령** | **가능** |
| **1순위 기관 전용** | **콜센터 번호, 앱 메뉴 경로** | **은행 재량** | **불가능** |

법령은 "금융회사에 요청한다"까지만 정하고, **어느 번호로 어떤 메뉴에서 하는지는 법령·보도자료 어디에도 없습니다.**

**재검증 주기는 1순위에만 의미가 있습니다.** 2·3순위는 자동으로 잡히므로 기다릴 이유가 없고, 1순위는 어떤 주기든 길 수 있습니다.
