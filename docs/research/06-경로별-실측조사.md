# 06 · 자금 유출 경로 10종 실측 조사

2026-08-16, 금융사기로 돈·가치가 빠져나갈 수 있는 **경로 10종**을 각각 조사하고 교차 검증했습니다.
[02-경유서비스-8유형.md](02-경유서비스-8유형.md)가 유형별 요약이라면, 이 문서는 **그 유형들을 실제 절차 단위로 뜯어본 결과**입니다.

조사 범위 — 은행 계좌이체(상호금융·우체국·저축은행 포함) · 인터넷전문은행/오픈뱅킹 · 간편송금/선불전자지급 ·
증권/CMA · 가상자산 · 대면편취/무통장입금 · 상품권·핀번호 · 휴대폰 소액결제 · 카드 부정사용/카드론 ·
명의도용/통장묶기.

> **조사의 한계를 먼저 적습니다.** 검증 단계에서 `fss.or.kr`·`fsc.go.kr`는 화면을 스크립트로 그리는 방식이라
> 본문을 받지 못했습니다. **금감원·금융위 보도자료에 근거한 항목은 1차 출처 대조를 못 했습니다** —
> 아래에서 신뢰도 **보도**로 표시한 것들이 그것입니다. 법령 조문은 국가법령정보·찾기쉬운 생활법령으로 확인했습니다.

## 1. 기존 자료의 오류 — 확정된 정정 4건

**반증 전담 검증에서 확정된 것들입니다.** 안내에 직접 영향을 줍니다.

### 1.1 소액 기준은 **1만원**입니다 (3만원 아님)

| 항목 | 값 |
| --- | --- |
| 기준 금액 | **1만원 이하** |
| 근거 | 통신사기피해환급법 제5조제1항제6호 + **시행령 제6조제2항** |
| 신뢰도 | **확인** (2026-08-16) |
| 출처 | https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1592&ccfNo=3&cciNo=1&cnpClsNo=2 |

**이 값은 두 규칙이 함께 참조합니다.** 틀리면 둘 다 어긋납니다.

1. **채권소멸절차 개시 공고 제외** — 잔액이 1만원 이하면 공고하지 않습니다(법 제5조제1항제6호).
2. **지급정지 종료** — 잔액이 1만원 이하이고 **지급정지일부터 90일 안에** 채권소멸절차가 개시되지 않으면
   지급정지 자체가 종료됩니다(시행령 제8조제1항제3호).

잔액 2만원 사건은 실제로는 공고가 자동 진행되는데, 3만원 기준으로 판정하면 소액 분기로 잘못 태워
불필요한 안내를 하고 90일 종료 판정까지 틀립니다.

### 1.2 사건사고사실확인원은 **온라인 발급**이 정식 채널입니다

| 항목 | 값 |
| --- | --- |
| 신청 방법 | **인터넷(정부24), 방문** |
| 수수료 | 없음 |
| 처리기간 | **3일** (야간민원은 익일) |
| 신뢰도 | **확인** (2026-08-16) |
| 출처 | https://www.gov.kr/mw/AA020InfoCappView.do?HighCtgCD=A08003&CappBizCD=13200000099 |

**"경찰서에 방문해 발급받으세요"로 안내하면 안 됩니다.** 피해 직후의 고령·거동불편 이용자에게
불필요한 관서 방문을 지시하는 것이고, 인터넷전문은행 이용자는 전 과정을 비대면으로 끝낼 수 있습니다.

> ⚠️ **처리기간 3일이 피해구제 신청 3영업일과 겹칩니다.** 확인원을 기다리다 3영업일을 넘기지 않도록
> **"먼저 접수하고 서류는 뒤따르게 하라"**는 안내가 함께 나가야 합니다.

### 1.3 「금융회사」 범위가 좁게 적혀 있었습니다

시행령 제2조가 추가하는 것은 축산업협동조합·산림조합만이 아닙니다.

| 근거 | 포함되는 것 |
| --- | --- |
| 법 제2조제1호 | 은행·산업은행·중소기업은행·수출입은행·상호저축은행과 중앙회·농협·수협·신협·새마을금고와 각 중앙회·**체신관서(우체국)** |
| **시행령 제2조** | 축산업협동조합·산림조합과 각 중앙회 · **여신전문금융회사** · **등록 대부업자 일부** (각 단서로 범위 한정) |

**신뢰도: 확인** (2026-08-16). → [05-미확인-목록.md](05-미확인-목록.md)의 **U-06 해소.**

### 1.4 카드 이용대금 이의제기 14일은 **법정 기한이 아닙니다**

여신전문금융업법 제16조제10항은 *"이의를 제기하면 조사를 마칠 때까지 그 금액을 받을 수 없다"*만 정하고
**신청 기한을 두지 않습니다.** 14일은 신용카드 개인회원 표준약관에서 온 **계약상 기한**이고 카드사마다 다를 수 있습니다.

법정 기한처럼 안내하면 14일이 지난 피해자가 **다툴 권리를 잃었다고 오해하고 포기합니다.**
**신뢰도: 확인**(조문) / 약관 부분은 **추론** — 카드사별 확인 필요.

## 2. 새로 확인된 법정 기한 — [01-환급절차-기한.md](01-환급절차-기한.md)에 없는 것들

**기한 계산 규칙에 반영되지 않으면 사건이 중간에 멈춥니다.**

| 기한 | 기산점 | 주인 | 근거 | 신뢰도 |
| --- | --- | --- | --- | --- |
| **채권소멸절차 개시 요청 30일** | 피해자가 **지급정지 통지를 받은 날** | **사용자** | 법 제5조제1항제6호 단서 | 확인 |
| **지급정지 종료 90일** | 지급정지일 | 금융회사 | 시행령 제8조제1항제3호 | 확인 |
| **명의인 이의제기 후 2개월** | 피해자가 **이의제기 사실을 통보받은 날** | 금융회사(해제 유보) | 법 제8조제2항제2호 | 확인 |
| **뒤늦은 피해구제 신청 2개월** | 채권소멸절차 **개시 공고일** | **사용자** | 법 제6조제1항 | 확인 |
| 카드 부정사용 보상 **소급 60일** | 신고 접수 시점에서 **거꾸로** | 카드사 | 여신전문금융업법 제16조제2항 | 확인 |
| 소액결제 정정요구 처리 **2주** | 정정요구를 받은 날 | 통신과금서비스제공자 | 정보통신망법 제58조제3항 | 확인 |

### 2.1 이 중 둘은 **사용자 기한**입니다

지금까지 정리된 사용자 기한은 3영업일 하나뿐이었는데, 실제로는 셋입니다.

- **잔액이 1만원 이하라고 통지받으면** → 30일 안에 채권소멸절차 개시를 **요청해야** 합니다.
  안 하면 90일 뒤 지급정지 자체가 풀립니다.
- **공고가 난 뒤에 피해 사실을 알았다면** → 공고일부터 2개월 안에 신청할 수 있습니다.

**둘 다 "통지를 받고도 무슨 뜻인지 몰라 넘기는" 전형적인 지점입니다** — 이 서비스가 개입할 자리입니다.

### 2.2 소급 기한이 하나 있습니다

카드 부정사용 보상은 **신고일에서 과거로 60일**을 봅니다. 조사한 10경로 중 유일하게 과거를 향해 세는 기한이라,
기한 계산이 전방향만 가정하면 **표현할 자리가 없습니다.**

## 3. 환급법 트랙이 **열리지 않는** 경우

법 제2조제2호 **단서** — **재화의 공급 또는 용역의 제공을 가장한 행위는 정의에서 제외**됩니다.
**대출의 제공·알선·중개를 가장한 행위는 포함**됩니다.

| 사기 유형 | 환급법 트랙 |
| --- | --- |
| 기관 사칭 · 대출 빙자 | **열림** |
| 물품 거래 사기 · 투자 유인(재화·용역 가장) | **안 열림** — 지급정지·피해구제 자체가 대상이 아님 |

**신뢰도: 확인**(조문). 진입 문진에서 이걸 가르지 못하면, 트랙이 열리지 않는 사용자에게
"은행에 전화해 지급정지를 거세요"라고 안내하게 됩니다.

## 5. 경로별 최장 기간 — 보존 기간 결정의 근거

**사건 데이터를 얼마나 들고 있어야 기능이 성립하는가**의 실측입니다.

| 경로 | 최장(일) | 가장 길게 잡는 단계 |
| --- | ---: | --- |
| 은행 계좌이체 | **180** | 공고 2개월 + 이의제기 시 2개월 |
| 가상자산 | **180** | 공고 2개월 (시행령 미확정) |
| 간편송금 | 150 | 공고 2개월 + 선불업자 통지 대기 |
| 휴대폰 소액결제 | 150 | 통신분쟁조정 60일(+30일 연장) |
| 인터넷은행·오픈뱅킹 | 120 | 공고 2개월 |
| 증권·CMA | 120 | 공고 2개월 |
| 카드·카드론 | 1,095 | 책임분담 신청 3년 (기한이지 진행 기간이 아님) |
| 명의도용·통장묶기 | 1,095 | 위와 같음. 통장묶기 자체는 130~135일 |
| 대면편취·무통장입금 | **상한 없음** | **검거 전에는 시계가 시작되지 않음** |
| 상품권·핀번호 | **상한 없음** | 형사 몰수·추징 환부 |

### 5.1 법정 골격만 더해도 90일을 넘습니다

```
전화 지급정지 D0
  → 피해구제 서류 3영업일 (미제출 시 +14일 유예)        ≈ D+20
  → 금융회사의 공고 요청 '지체 없이' (실무 수일)          ≈ D+25
  → 채권소멸절차 개시 공고 2개월                          ≈ D+86
  → 채권 소멸 → 환급금 결정 14일                          ≈ D+100
  → 금융회사 지급 '지체 없이'
```

**여기에 명의인이 이의를 제기하면 피해자 통보일부터 2개월(≈61일)이 통째로 얹혀 ≈160일이 됩니다.**

> ⚠️ **[ADR-010](../../decisions/010-case-store.md)의 보관 90일과 어긋납니다.**
> ADR-010은 이 값을 *"근거가 약하다"*고 스스로 적어 두었고, *"환급이 6개월 걸리는 경우는 덮지 못한다"*고
> 명시했습니다. 이번 실측은 **6개월 케이스만이 아니라 정상 진행 케이스도 90일에 걸린다**는 것을 보여줍니다 —
> 공고 2개월 하나만으로 D+86이고, 환급금 결정 14일이 그 뒤에 붙습니다.
>
> **바꾸려면 새 ADR이 필요합니다.** 이 문서는 사실만 제시합니다.

### 5.2 상한이 없는 경로가 둘입니다

대면편취는 **검거되지 않으면 절차가 영영 시작되지 않고**, 상품권은 형사 몰수·추징 환부에 상한이 없습니다.
**이 둘을 숫자 하나로 뭉개면 "넉 달 뒤면 끝난다"는 잘못된 기대를 줍니다.**

## 6. 8유형에서 빠진 경로 — 카드

[02-경유서비스-8유형.md](02-경유서비스-8유형.md)의 8유형에 **카드 부정사용·카드론이 없습니다.**

| | 8유형의 다른 경로 | 카드 |
| --- | --- | --- |
| 근거법 | 통신사기피해환급법 | **여신전문금융업법 제16조** |
| 손실의 형태 | 나간 돈 | **남은 빚** (카드론·현금서비스) |
| 지급정지 | 사기이용계좌를 정지 | **가맹점 결제분은 정지 대상 자체가 없음** |
| 기한 방향 | 앞으로 | **소급 60일** |

**다른 경로에 조건문으로 붙이면 뭉개집니다.** 별도 경로로 두어야 합니다. — **신뢰도: 확인**(조문 기준)

### 6.1 분류 축이 하나로는 부족합니다

통장묶기·명의도용은 *"돈이 어느 경로로 나갔나"*가 아니라 *"이 사람이 피해자인가, 정지의 대상이 된 명의인인가"*를
묻습니다. 근거법은 같은데 **조문이 반대로 작동**합니다 — 피해자는 제3조·제10조, 명의인은 제7조·제8조.

그리고 이 축은 경로와 **직교**합니다: 은행 계좌도 간편송금 계정도 묶일 수 있고,
도용된 명의로 개설된 계좌가 대포통장으로 쓰이면 한 사람이 **양쪽 다**가 됩니다.

> `spec/common/08-14-api.md`가 이미 `track: victim | frozen_account`을 두고 있어 이 축이 반영돼 있습니다.
> 경로 분류(`CH-*`)를 바꾸는 것은 [ADR 없이 하지 않습니다](../../spec/backend/08-14-channel-matrix.md).
