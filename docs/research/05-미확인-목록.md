```

```

> ⬜ **특별법에 별도 규정이 있는지 확인하지 못했습니다.** 조문 전문 대조 전까지 **추론**입니다.

### U-22 — 무통장입금 (2026-08-18 **완화**, 해소는 아님)

**법 제2조제2호의 네 목 전문을 확보했습니다.**

| 목 | 전문 |
| --- | --- |
| **가목** | 자금을 **송금·이체하도록** 하는 행위 |
| 나목 | 개인정보를 알아내어 자금을 **송금·이체**하는 행위 |
| 다목 | 자금을 **교부받거나 교부하도록** 하는 행위 |
| 라목 | 자금을 **출금하거나 출금하도록** 하는 행위 |

- https://casenote.kr/법령/전기통신금융사기_피해_방지_및_피해금_환급에_관한_특별법/제2조 (확인 2026-08-18)

**무통장입금은 가목이 유력합니다.** 근거 셋입니다.

1. **결과가 「계좌로 들어간 돈」입니다.** 현금으로 냈을 뿐 도착지는 사기이용계좌이고,
   문언상 **송금**에 해당합니다.
2. **다목·라목이 피해자 신청권을 뺀 이유는 「정지할 계좌를 특정할 수 없어서」입니다.**
   대면 현금 교부(다목)와 통장·카드 교부 후 인출(라목)은 계좌가 없거나 피해자가 모릅니다.
   **무통장입금은 입금증에 상대 계좌번호가 찍힙니다** — 특정이 됩니다.
3. 라목의 「출금」은 **사기범이 빼가는 행위**이지 피해자가 넣는 행위가 아닙니다.

> ⚠️ **그래도 유권해석은 없습니다. 신뢰도 「추론」(조문 문언)입니다.**
> **안내 방침** — 가목으로 보고 「은행에 지급정지 요청 + 3영업일 신청」을 안내하되,
> **「거절될 수 있습니다」를 함께 붙입니다.** 안내를 못 하던 상태에서 안내하는 상태가 됐지만,
> **단정하지는 않습니다.**
