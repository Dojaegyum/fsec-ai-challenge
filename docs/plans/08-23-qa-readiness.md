# QA 까지 남은 일

> 2026-08-23 작성. **세션이 바뀌어도 이어받는 자리입니다** — 컴팩트 뒤에 이 파일부터 여세요.
>
> 조사한 사실만 적었습니다. 각 태스크의 「지금 상태」는 그날 코드를 직접 보고 쓴 것이고,
> **틀렸으면 고치는 것까지가 그 태스크입니다.**

## QA 가능이란 무엇인가 — 이 문서가 겨누는 선

**한 사람이 브라우저로 이 한 바퀴를 실제 서버로 돌 수 있는 것**입니다.

```
/start 에서 동의 → 사건 생성 → 링크 받음
  → 진술 한 턴 → 슬롯 하나 답함 → 플랜이 뜸
  → 파일 하나 올림 → 전사가 뜨고 파란 토큰이 보임
  → 브라우저 닫음 → 받은 링크로 다시 들어옴 → 플랜이 그대로 있음
```

**목업이 아니라 서버 응답으로** 이게 되면 QA 를 시작할 수 있습니다.
화면 대부분이 **08-24 에 실제 응답으로 옮겨졌습니다** — 남은 것은 증거함과, 값을
보내는 쪽(발화·업로드)입니다.

## Task 9: 배선하며 발견한 것 셋 — **사람이 정해야 합니다**

### ① 슬롯 답변이 서버로 안 갑니다 — 어느 경로인지가 안 정해졌습니다

질문 버튼을 눌러도 오른쪽 열만 바뀌고 **답이 서버에 안 갑니다.**
자리는 §3.5 `PATCH …/slots/{slot_key}` 이고 라우트도 서 있습니다. 막힌 것은 **PII 경계**입니다.

| 묻는 것 | 왜 안 정해졌나 |
| --- | --- |
| **타이핑한 `value` 가 `outgoing()` 을 지나야 하나?** | 지나야 한다면 서버는 토큰만 받습니다. 그런데 §3.5 응답에 **`pii_confirm`** 이 있어 「서버가 값을 보고 개인정보인지 묻는다」로 읽힙니다 ([ADR-041](../../decisions/041-pii-confirm-with-user.md)) — 토큰만 받으면 그 판단을 할 수 없습니다 |
| `action: "mask"` 는 무엇을 가리나 | 이미 토큰이면 가릴 것이 없고, 원문이면 그때까지 서버가 원문을 들고 있었다는 뜻입니다 |

**버튼 선택지는 서버가 준 문자열이라 PII 가 없습니다** — 그 경로만 먼저 열 수도 있습니다.
다만 「모름」을 `action: "unknown"` 으로 보낼지 판단이 필요하고, 그 표시가 §3.4 `options` 에
**없습니다**(`chat-handler` 가 문구로 알아봅니다).

- [ ] `value` 가 경계를 지나는지 정한다 → [PII 격리 경계](../../spec/common/08-14-pii-boundary.md)에 한 줄
- [ ] 정해지면 `PATCH …/slots/{slot_key}` 를 컴포저·버튼에 잇는다

### ② `pii-masker` 가 목업의 계좌번호를 「카드」로 집습니다

`110-2345-678901` 은 13자리이고 Luhn 을 통과합니다. `CARD` 가 **13~19자리**를 보고
`PATTERNS` 에서 계좌보다 **먼저** 오기 때문에 `[카드-1]` 이 됩니다.

**새는 것은 아닙니다** — 어느 쪽으로 잡히든 가려져 나갑니다. 어긋나는 것은 셋입니다.

- 화면에 보이는 이름표 (「카드」 vs 「계좌」)
- §3.9 의 **종류별 부분 복원** 규칙이 갈립니다
- 계좌 슬롯이 안 채워질 수 있습니다

국내 카드는 15~16자리이고 13자리 Visa 는 사실상 없습니다. 계좌는 11~14자리입니다.
**`CARD` 의 하한을 14로 올리면 해결되지만** `pii-masker` 의 판단이라 손대지 않았습니다.

- [ ] 하한을 올릴지 정한다 → `src/modules/pii-masker/patterns.ts` · 그 모듈 README

### ③ 재진입하면 지난 대화가 안 보입니다

§3.10 에 **메시지 이력이 없습니다.** 그래서 며칠 뒤 링크를 열면 챗이 비어 있습니다.
`case-opener` 가 플랜으로 열기 때문에 **빈 챗을 먼저 보게 되지는 않지만**, 챗으로 가면 빕니다.

- [ ] 이력을 내릴지 정한다 — §3.10 에 얹을지, 별도 엔드포인트로 둘지, **안 보여줄지**

## 순서

**Task 1 이 먼저입니다** — 환경변수가 없으면 나머지를 확인할 방법이 없습니다.

```
1 환경변수  ─┬─→ 5 사건 생성·재진입 ──→ 2 화면 배선 ──→ 6 파일 ──→ 3 발화
             └─→ 4 서버가 빠뜨린 칸 넷 (백엔드 · 2·6 과 나란히)
                                                        └─→ 8 스모크
7 관리자·크론 — 범위를 먼저 정하고, 넣으면 아무 때나
```

**2 와 4 는 나란히 갈 수 있습니다.** 화면은 값이 없으면 안 그리는 쪽으로 이미 서 있어서
(`days_left` 없으면 D-day 를 안 그림), **서버가 늦어도 배선은 깨지지 않습니다.**
