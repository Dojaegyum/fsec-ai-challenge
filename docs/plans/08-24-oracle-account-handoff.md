# 오라클 계정을 하나 더 여는 절차 — 팀원용

> 2026-08-24 작성. **팀원에게 그대로 전달하는 문서입니다.**
>
> 클라우드를 처음 다루는 사람도 따라올 수 있게 화면에 보이는 글자 그대로 적었습니다.
> 아래 「직접 겪은 함정」은 전부 2026-08-23 에 실제로 막혔던 자리입니다.

## 왜 부탁드리나 — 30초 요약

이 서비스는 **통화 녹음을 글로 옮기고 화면 캡처에서 글자를 읽는 서버**가 필요합니다.
모델을 직접 돌려야 해서 **메모리 6GB 이상**이 필요한데, 오라클이 그 크기를
**영구 무료**로 줍니다.

그런데 **무료 자리가 없습니다.** 지금 계정(일본 오사카)으로 **19시간 동안 394번**
시도해서 한 번도 못 잡았습니다.

**자리는 지역마다 따로 있습니다.** 그래서 다른 지역에 계정을 하나 더 열어
동시에 두드리려는 것입니다. 둘 중 먼저 잡히는 쪽을 씁니다.

| | |
| --- | --- |
| 걸리는 시간 | **20분** (대부분 가입 절차) |
| 비용 | **0원** — 카드는 본인 확인용이고 청구되지 않습니다 |
| 부탁드릴 것 | 가입 · 네트워크 만들기 · 접속 열쇠 발급 **셋** |
| 안 하셔도 되는 것 | **서버 만들기** — 프로그램이 자리가 날 때까지 대신 두드립니다 |

## ⚠️ 시작 전에 — 되돌릴 수 없는 선택이 **하나** 있습니다

가입할 때 고르는 **지역(Home Region)** 은 **나중에 절대 못 바꿉니다.**
그리고 **무료 자원은 그 지역에서만** 쓸 수 있습니다.

### 골라야 할 것 — `US East (Ashburn)`

왜 이곳인지는 근거가 있습니다. 오라클의 **가용성 도메인**(같은 지역 안에서
물리적으로 분리된 데이터센터 묶음) 수를 보면 —

| 지역 | 가용성 도메인 |
| --- | --- |
| **US East (Ashburn)** | **3** |
| US Midwest (Chicago) · US West (Phoenix) | 3 |
| Germany Central (Frankfurt) · UK South (London) | 3 |
| 서울 · 도쿄 · 오사카 · 싱가포르 **를 포함한 나머지 33곳** | **1** |

**자리는 도메인마다 따로 있습니다.** 오라클이 자리 없다고 거절할 때
*"다른 가용성 도메인에서 시도해 보세요"* 라고 안내하는 것이 그 뜻입니다.
지금 오사카는 도메인이 하나뿐이라 그 조언을 쓸 수가 없었습니다.

**도메인이 3개면 한 바퀴에 세 번 두드립니다.** 그리고 도메인이 3개라는 것은
오라클이 그만큼 오래 키운 큰 지역이라는 뜻이라, 장비 자체도 많습니다.

> ⛔ **`South Korea North (Chuncheon)` 은 고르면 안 됩니다.**
> 오라클이 이 지역에서만 무료 ARM 서버 생성을 막아 뒀습니다.

> ℹ️ **데이터가 미국에 놓이는 것**은 이 서버를 **시연용으로만** 쓰기 때문에
> 받아들입니다. 시연에는 합성 데이터만 올리고, 발표에서 **「운영에서는 토큰화
> 이전 단계를 국내에서만 돌린다」** 를 명시합니다. 이 조건은 GPU 호스팅 결정
> (아직 병합 전 · `decisions/gpu-hosting` 가지)에서 온 것입니다.

### 2. 계정 정보

| --- | --- |

| Name · Email | 본인 것 |

**메일로 인증 링크가 옵니다.** 눌러서 다음으로 넘어갑니다.

### 3. ⚠️ 여기가 되돌릴 수 없는 화면입니다

**`Home Region`** 을 고르는 칸이 나옵니다.

```
Home Region:  US East (Ashburn)   ← 이것으로
```

**고르고 나면 못 바꿉니다.** 목록에서 `US East (Ashburn)` 을 찾아 선택하세요.

### 4. 카드 등록

**본인 확인용입니다.** 오라클이 1달러 정도를 잠시 승인 요청했다가 취소합니다
(실제 청구 아님). 무료 등급만 쓰는 한 요금이 나오지 않습니다.

### 5. 가입 완료

콘솔(관리 화면)에 들어가집니다. 오른쪽 위에 **`US East (Ashburn)`** 이라고

## ② 네트워크 만들기 — 약 5분

서버가 인터넷과 통하려면 네트워크가 먼저 있어야 합니다.

### 1. 메뉴 찾기

왼쪽 위 **햄버거 메뉴(≡)** → **Networking** → **Virtual cloud networks**

### 2. ⚠️ 함정 — 버튼이 둘인데 하나만 맞습니다

목록 화면에 **`Create VCN`** 버튼이 크게 보입니다. **그걸 누르면 안 됩니다.**
그것은 껍데기만 만들고 **안이 비어 있어서**, 나중에 서버를 만들 때 고를 것이
아무것도 없습니다.

**`Actions` 드롭다운을 열어 `Start VCN Wizard` 를 찾으세요.**

> 실제로 이 함정에 빠져서 만든 것을 버리고 다시 했습니다.
> 화면 버전에 따라 `Start VCN Wizard` 가 목록 위쪽에 따로 있기도 합니다.

### 3. 마법사

선택지 둘 중 **왼쪽**을 고릅니다.

```
✅ Create VCN with Internet Connectivity
❌ Add Internet Connectivity and Site-to-Site VPN to a VCN
```

왼쪽 카드 아래 `Includes:` 에 이렇게 적혀 있으면 맞습니다 —
*VCN, public subnet, private subnet, internet gateway, NAT gateway, service gateway*

### 4. 이름만 넣고 나머지는 그대로

| 칸 | 넣을 것 |
| --- | --- |
| VCN Name | `finally-net` |
| Compartment | 기본값 그대로 |
| **그 아래 주소 값 전부** | **하나도 건드리지 마세요** |

`Next` → `Create`. 1분쯤 걸리고 항목마다 초록색 체크가 뜹니다.

### 5. ⚠️ 포트 열기 — 이걸 빼먹으면 나중에 원인 찾기가 어렵습니다

마법사는 **접속용 통로(22번)만** 열어 둡니다. 우리 서비스가 쓸 통로는
직접 열어야 합니다.

> 만들어진 **`finally-net`** 클릭 → 위쪽 탭에서 **`Security`**
> → **`Default Security List for finally-net`** 클릭
> → **`Add Ingress Rules`**

**두 줄**을 추가합니다.

| Source CIDR | IP Protocol | Destination Port Range |
| --- | --- | --- |
| `0.0.0.0/0` | TCP | `80` |
| `0.0.0.0/0` | TCP | `443` |

`Stateless` 체크박스는 **끈 채로** 두세요.

> 화면 버전에 따라 `Security` 가 탭이 아니라 왼쪽 `Resources` 목록에
> **`Security Lists`** 로 있기도 합니다. 둘 다 같은 곳입니다.

## ③ 접속 열쇠 발급 — 약 3분

제가 프로그램으로 자리를 두드리려면 계정에 접근할 열쇠가 필요합니다.

### 1. 발급

> 오른쪽 위 **사람 아이콘** → **My profile**
> → 왼쪽 아래 **API keys** → **Add API key**
> → **`Generate API key pair`** 선택
> → **`Download private key`** 눌러 파일 내려받기 ← **꼭 받으세요**
> → **`Add`**

### 2. 화면에 뜨는 설정 복사

`Add` 를 누르면 **`Configuration file preview`** 상자가 뜹니다.
이런 다섯 줄입니다.

```
[DEFAULT]
user=ocid1.user.oc1..aaaa................
fingerprint=a1:b2:c3:................
tenancy=ocid1.tenancy.oc1..aaaa................
region=us-ashburn-1
key_file=<path to your private keyfile>
```

**그 다섯 줄을 통째로 복사**해 두세요.

> 창을 닫았으면 다시 볼 수 있습니다 — **API keys** 목록에서 방금 만든 줄의
> **점 세 개(⋯)** → **View configuration file**

## ④ 저에게 주실 것 — 둘

1. **복사한 설정 다섯 줄**
2. **내려받은 `.pem` 파일** (또는 그 파일이 있는 경로)

### 이 값들이 비밀인가

**`.pem` 파일 하나만 비밀입니다.** 나머지 다섯 줄은 계정을 가리키는 번호일
뿐이라 그 자체로는 아무것도 못 합니다.

| 값 | 무엇 | 비밀인가 |
| --- | --- | --- |
| `user` · `tenancy` | 계정 안의 번호 | 아니오 |
| `fingerprint` | 열쇠를 알아보는 요약값 | 아니오 |
| `region` | `us-ashburn-1` | 아니오 |
| **`.pem` 파일** | **실제 열쇠** | **예** |

`.pem` 파일은 채팅에 붙여넣지 마시고 **파일로 전달**하거나 경로만 알려 주세요.

## ⑤ 그다음은 안 하셔도 됩니다

서버를 직접 만들려고 하면 **십중팔구 「Out of capacity」로 거절당합니다.**
그래서 사람이 누르는 대신 **프로그램이 계속 두드립니다.**

제가 하는 일 —

1. 받은 열쇠로 접속 설정
2. 필요한 값(가용성 도메인 3개 · 서브넷 · 운영체제 이미지)을 **자동으로 조회**
3. 3분마다 **도메인 3개 × 크기 2가지 = 6번** 시도
4. 자리가 나면 **즉시 잡고** 서비스까지 올림

전부 2026-08-23 에 실제로 막혔던 자리입니다. 위 절차대로 하면 안 만납니다.

| 무엇 | 왜 막히나 |
| --- | --- |
| 춘천 지역 선택 | 오라클이 그 지역에서만 무료 ARM 생성을 막아 뒀습니다 |
| `Create VCN` 버튼 | 껍데기만 만듭니다. `Start VCN Wizard` 가 맞습니다 |
| 공인 IP 스위치가 안 눌림 | 네트워크가 없을 때 잠깁니다. 마법사를 먼저 |
| 서브넷 목록이 비어 있음 | 위와 같은 원인 |
| 서버 크기에 ARM 이 안 보임 | 목록 위 **`Ampere` 탭**을 눌러야 나옵니다 |
| 기본 크기가 1코어·6GB | 무료 한도는 2코어·12GB 입니다 |
| 운영체제에 `Minimal` 선택 | 기본 도구가 빠져 설치가 첫 줄에서 멈춥니다 |

## 자주 나올 질문

**요금이 나오나요?**
무료 등급만 쓰면 안 나옵니다. 카드는 본인 확인용입니다. 가입 후 30일간
체험 크레딧이 붙는데, 우리는 **무료 한도 크기만** 요청하므로 그것도 안 씁니다.

**계정이 나중에 문제가 되나요?**
서버 한 대를 무료 한도 안에서 쓰는 것뿐이고, 대회가 끝나면 지우면 됩니다.
**한 사람이 계정을 여러 개 만드는 것은 약관 위반**이라, 반드시 **본인 명의로
처음 만드는 계정**이어야 합니다.

**얼마나 걸리나요?**
가입 10분 · 네트워크 5분 · 열쇠 3분. 그 뒤로는 기다리기만 하면 됩니다.

**자리가 안 나면요?**
국내 유료 서버(월 26,400원)로 갑니다. 그 경우에도 이 계정은 그대로 두고
계속 두드립니다 — 나중에 잡히면 옮기고 한 달치만 쓰면 됩니다.
