## 파일

| 파일 | 무엇 |
| --- | --- |
| `eval-set.json` | 평가셋 40발화 + 정답 라벨 (`pii` 33 · `keep` 80) |
| `transcripts.json` | 7개 전사 조건(`{base,small,medium} × {phone,phone_noisy}` + 숫자유도)의 전사문 전문 |
| `results.json` | 탐지기별 채점 결과. 발화별 상세는 **틀린 것만** 담았습니다 |

## ⚠️ 두 가지

**1. 평가셋의 계좌·주민번호·전화·이름은 전부 실존하지 않는 임의값입니다.**
실제 피해자 데이터가 아닙니다. 기관명·대표번호는 8유형 분기 검증에 필요해 실명을 쓰되 값은 예시입니다.

**2. 숫자는 TTS 합성 음성 기준의 낙관적 하한값입니다.**
실제 통화는 울먹임·말 끊김이 섞이므로 오독률이 이보다 나쁩니다.

## 다시 쓸 때

`transcripts.json`이 있어 **전사를 다시 돌리지 않고 탐지기만 바꿔 잴 수 있습니다**(CPU로 40분 절약).
`pii-tokenizer`를 구현하면 이 평가셋이 그대로 회귀 테스트가 됩니다 — 누출 0건·과차단 0건이 통과 기준입니다.
