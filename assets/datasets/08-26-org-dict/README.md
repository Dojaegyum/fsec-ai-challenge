## 초안 → 사전, 한 바퀴 돈 첫 사례

카드사 아홉이 이 폴더를 거쳐 `src/kb/org.json` 으로 갔습니다(2026-08-26).

```bash
python verify_source.py "https://www.crefia.or.kr/portal/company/membership/membershipIntroduction.xx?coCodeSubId=1" CH-card
#  9/9 확인 → 이 URL 을 그 아홉의 source_url 로
```

**요약시키지 않았습니다.** 모델에게 「이름을 뽑아 줘」라고 하면 없는 이름이
만들어질 수 있습니다(`org.json` 의 `_note` 가 기록한 사고). 방향을 뒤집어
**아는 이름이 원문에 있는지**만 보면 만들어질 이름도, 밀릴 이름도 없습니다.

## ⚠️ 둘

**① 「2/2」를 비율로 읽지 마세요.** 전사에서 **회수 가능했던 것이 2건**뿐입니다 —
나머지 7건은 애초에 사전에 없어 모수에서 빠졌습니다. 화면도 7건입니다.

**② 거리 임계값을 정밀하게 맞추면 과적합입니다.** 화면 20장·발화 40개에서 고른
값이라, **경로마다 다르다**는 것까지가 이 측정이 말할 수 있는 전부입니다.

## 사전을 넓히면

`src/kb/org.json` 에 유형을 더한 뒤 **이 스크립트를 다시 돌리면 바로 비교됩니다** —
전사·판독을 다시 할 필요가 없습니다. 지금 비어 있는 일곱 유형은
[17 §1](../../../docs/research/17-기관명-사전-실측.md) 에 있습니다.

**초안을 미리 대 보려면 `--with-draft` 를 붙입니다.** 적재는 안 되지만
(출처가 비어 `kb-load.ts` 가 거부합니다) **출처를 채우면 얼마나 나아지는지**는
지금 볼 수 있습니다 → [17 §9](../../../docs/research/17-기관명-사전-실측.md).

## 임계값은 거리가 아니라 **표기 길이**입니다

사전을 넓히자 「화면 거리 1 · 오탐 0」이 깨졌는데(32곳에서 오탐 4),
**범인이 전부 세 글자 표기**였습니다 — `카페이`·`네페이`·`N페이`·`페이코`.
세 글자에 거리 1 을 주면 **두 글자만 맞아도 걸립니다.**

그래서 `find()` 에 `fuzzy_from`(거리를 허용할 최소 표기 길이)을 두고 재 봤습니다.

```
거리 1              전사 5/9 · 오탐 17    화면 5/10 · 오탐 5
거리 1 · 4자 이상만   전사 5/9 · 오탐  0    화면 5/10 · 오탐 0   <- 회수 그대로, 오탐만 0
거리 1 · 5자 이상만   전사 5/9 · 오탐  0    화면 3/10 · 오탐 0   <- 회수가 떨어집니다
```

**32곳에서도 57곳에서도 오탐 0 입니다** — 사전이 커져도 버팁니다.
자세한 것은 [17 §9 ③](../../../docs/research/17-기관명-사전-실측.md).
