## ⚠️ 둘

**① 「2/2」를 비율로 읽지 마세요.** 전사에서 **회수 가능했던 것이 2건**뿐입니다 —
나머지 7건은 애초에 사전에 없어 모수에서 빠졌습니다. 화면도 7건입니다.

**② 거리 임계값을 정밀하게 맞추면 과적합입니다.** 화면 20장·발화 40개에서 고른
값이라, **경로마다 다르다**는 것까지가 이 측정이 말할 수 있는 전부입니다.
