# Handoff: S-11 「이 답변에 무엇이 나갔나」 + 전사 검수 패널 (WS 유형 추가)

## Overview
FinAlly `/c/{token}`의 두 추가 화면: 챗 답변 버블 클릭 시 열리는 **S-11 공개 화면**과, 오른쪽 350px 열에 들어가는 **전사 검수 작업 패널**(WS 유형 추가분). 대상 저장소 `Dojaegyum/fsec-ai-challenge`. 3열 셸(T0 288px | 본문 | 350px)은 이미 구현된 것을 전제로 그렸습니다.

## About the Design Files
`.dc.html`은 브라우저에서 열리는 HTML 디자인 레퍼런스입니다(`support.js` 필요). 프로덕션 코드가 아니며, 저장소 환경(Next.js + Tailwind v4 + globals.css 토큰)으로 재구현하세요.

## 화면 1 — S-11 시트 (1a)
- **트리거**: AI 답변 버블 클릭(버블 전체가 히트 영역). 열림 동안 버블에 pii 칩 「이 답변에 무엇이 나갔나 · 보는 중」
- **시트**: 600px 중앙, radius 18px, border `oklch(0.386 0.016 274/80%)`, bg stage, 백드롭 62% 딤+블러 5px — 동의 모달과 같은 문법
- **구성 순서**: ① 헤더(제목 + "밖으로 나간 것은 이것뿐입니다" + ✕) ② 「그대로 나간 문장」 인용 카드(가려진 칩 인라인) ③ 「바뀐 것」 대응표 — 헤더 행 "원문 — 이 기기에서만 보입니다 / 밖으로 나간 것", 행: 원문 → 칩 ④ 「이 답변이 참고한 것」 ◆ 매뉴얼명 + 시행일 ⑤ pii 안심 카드("원문은 이 기기 밖으로 나가지 않았습니다") ⑥ [확인했어요] 흰 버튼 48px
- **금지 (스펙)**: AI 판단 근거·프롬프트 전문 노출, 기술 용어(토큰·프롬프트·API — 화면 어휘는 「가려진 것」「나간 것」「바뀐 것」)
- **데이터**: 대응표·나간 문장은 해당 턴의 실제 전송 페이로드에서. 원문 열은 이 기기 로컬 복원값 — 다른 기기에서 열면 원문 열이 칩과 동일해짐(그 상태도 정상 표기 필요, 1d와 같은 어휘 사용)

## 화면 2 — 전사 검수 패널 (1c · 1d)
- **WS 골격 ①~⑦ 그대로**: 눈썹 「읽은 값 확인」(한글만) · 제목 · 상태 칩(확인 n/3, pii) · 내용 · 부산물 각주(◆ 확인한 값은 신청서 초안에) · 주 행동 [확인 끝냈어요] 흰 44px · [나중에 할게요] 동일 크기 상시
- **값 행 레이아웃(수정 반영)**: 원본 조각(크롭) 박스 → 라벨+값 풀폭 한 줄 → 버튼 행 [맞아요][고칠게요] (40px, 아래 정렬). 값이 버튼에 밀려 꺾이지 않도록 이 순서 고정 — 350px 실폭 검증됨
- **자신 없는 값**: 카드·크롭 테두리 앰버 + `!` 원형 기호 + 「자신이 없습니다」 — 색만으로 가르지 않음
- **확인됨 상태**: [✓ 맞아요] pii 14% bg 단일 칩
- **비관문**: 안 해도 진행. 안 고친 값은 「미확인」 유지
- **1d 갈림길 (다른 기기)**: 크롭 자리에 안내 카드 「이 기기에는 원본이 없습니다 / 고장이 아닙니다」, 값은 가려진 칩(금액·1, 계좌·1) 또는 평문(시각) + 「미확인」 태그, 점선 테두리. pii 카드로 "처음 올린 기기에서 열면 원본과 나란히 확인" 안내. 주 행동 [알겠어요 — 계속 진행]
- **크롭 데이터**: 원본 이미지는 기기(IndexedDB 등)에만 — 서버는 좌표(bbox)와 읽은 값만 가짐. 다른 기기 = 좌표는 있으나 이미지 없음 → 1d 상태

## State Management
- S-11: `GET …/turns/{id}/disclosure` (턴별 전송 페이로드 + 인용 근거) — 원문 복원은 클라이언트에서만
- 검수: 값별 상태 `unconfirmed | confirmed | corrected | unavailable` — 서버 push(OCR 신뢰도 낮은 필드 목록)로 패널 열림, 「나중에」 시 전부 unconfirmed 유지
- 원본 존재 여부: 로컬 저장소 조회 실패 시 1d 렌더 — 에러 상태 아님(로깅도 info 레벨)
