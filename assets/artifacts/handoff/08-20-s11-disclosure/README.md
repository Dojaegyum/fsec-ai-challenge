| 볼 것 | 결과 |
| --- | --- |
| 도메인 토큰만 · 빨강 없음 | **통과** — `oklch` 278곳. 유일한 hex 색 `#2a78d6` 은 레퍼런스 뷰어의 옵션 번호 배지이고 시안이 아닙니다 |
| 실제 텍스트 12.5px 미만 없음 | **통과 (조건부)** — 11px·10px 은 전부 원형 배지 안의 글리프(`✓` `○` `!`)입니다. **구현할 때 `aria-hidden` 이어야 합니다** |
| 장식에 뜻 없음 | 통과 |
| `prefers-reduced-motion` 이 전부 멈춤 | 통과 — `*` 전체 규칙. `@keyframes pulse-dot` 은 정의만 되고 쓰이지 않습니다 |
| 색만으로 구분하지 않음 | **통과** — 「자신이 없습니다」가 앰버 + `!` 글리프 + **글자**를 함께 씁니다 |

| 「받을 수 있다」로 읽히지 않음 | 통과 |

## spec 과 어긋난 것 — 사람이 정합니다

**임의로 맞추지 않았습니다** ([RFC-003](../../../../rfc/003-design-handoff.md) 「시안이 spec과 어긋나면」).

| 어긋난 것 | 시안 | spec |
| --- | --- | --- |
| **패널 유형 이름** | `WS-review` | 유형명은 `WS-{action}` 꼴이고 `body.action` 여덟째 값을 **`confirm`** 으로 정했습니다 → **`WS-confirm`** 이어야 합니다 |
| **`S-11` 이 등재돼 있지 않습니다** | 새 화면 ID 로 그려 왔습니다 | [화면 설계](../../../../spec/frontend/08-14-screens.md)는 `S-03`~`S-10` 까지입니다 |
| **패널 유형이 여덟이 됩니다** | 검수 패널 추가 | [워크스페이스 패널](../../../../spec/frontend/08-17-workspace-panels.md) 「유형 일곱」 |
| **`GET …/turns/{id}/disclosure`** | 새 엔드포인트를 전제 | [API 계약](../../../../spec/common/08-14-api.md)에 없습니다 |
| **크롭 좌표(bbox)** | 서버가 좌표와 읽은 값을 갖는다 | [데이터 모델](../../../../spec/backend/08-16-data-model.md)에 좌표 칸이 없습니다 |

**적용 전에 이 다섯이 정해져야 합니다.** 넷은 계약을 늘리는 것이라
[ADR-020](../../../../decisions/020-adr-threshold.md) 기준으로 ADR 대상입니다.
