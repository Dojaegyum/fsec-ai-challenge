## 받은 그대로입니다

`.dc.html` 셋과 `canvas.json` 은 캔버스에서 그대로 꺼낸 **디자인 레퍼런스**입니다. 프로덕션 코드가 아니라
의도한 모양의 원본이고, 저장소 환경으로 **재구현**합니다.

| 파일 | 무엇 |
| --- | --- |
| `Main.dc.html` | **확정안.** 조문 기준 목록 + 상세(직전/이번 · 닿는 매뉴얼 · 판단). 왼쪽 위 「조문 기준 ↔ 매뉴얼 기준」 렌즈, 닿는 매뉴얼 행의 「매뉴얼 기준으로 →」 |
| `DirectionB.dc.html` | 탈락 — 두루마리. 760px 한 열에 변경 하나가 카드 하나 |
| `DirectionC.dc.html` | 탈락 — 매뉴얼 기준. 장점(항목 단위)은 확정안의 렌즈로 흡수. 항목별 결론(손댐 필요 / 영향 없음)은 다음 단계 후보 |
| `canvas.json` | 아트보드 배치와 페이지, 방향별 동기·트레이드오프 메모 |

`symbol-mark.png` 는 이미 `src/public/brand/` 에 있어 담지 않았습니다.

## 시안이 사용자 손으로 고쳐진 자리

캔버스에서 저장된 판(2026-09-06 16:54)에 문구 둘이 바뀌어 있습니다. 메모 자리표시 「메모 예시: 시행일 미정,
10월 재확인」은 그대로 씁니다. 승인 단추 「승인 완료 및 반영」은 **쓰지 않습니다** — 승인이 곧 반영이 아니라는
[RFC-002](../../../../rfc/002-kb-authoring.md) 와 어긋나 「승인」으로 되돌립니다(ADR-088 「근거」).
스냅샷은 규약대로 고치지 않고 그대로 둡니다.

## 무엇을 그대로 옮겼나 — 사건 화면의 값들

시안은 `src/app/c/[token]/page.tsx` 와 `globals.css` 의 값을 그대로 씁니다. 헤더(56px · `--stage` · hairline),
칩(둥근 · `--chip` · 13px), 알약 내비(44px · 활성 `oklch(1 0 0/12%)`), 행(11px 모서리 · `--surface` · 안쪽 그림자),
패널(18px 모서리 · `--stage`), 눈썹 라벨(12.5px · 620 · 0.13em), 토큰 칩(`--pii-bg` · 6px 모서리).
상태는 색이 아니라 글자로 가릅니다 — 「최초 수집」「새 조문」 배지는 중립 칩이고, 앰버·horizon 을 쓰지 않았습니다.
