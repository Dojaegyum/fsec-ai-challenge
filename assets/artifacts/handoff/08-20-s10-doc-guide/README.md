| 모션이 감속 모드에서 멈춤 | **통과** — `transition-colors` 뿐이고 `globals.css` 가 `transition-duration` 까지 덮습니다 |

### ✗ `--color-icon` 을 **본문 글자 아홉 곳**에 썼습니다

[tokens](../../../../spec/frontend/design-system/08-16-tokens.md)에 **⚠️ 「글자에 쓰지 마세요」**가
이미 적혀 있고 실측값까지 있습니다 — `--surface` 위 **4.43:1**, `--panel-top` 위 **4.27:1**로
본문 기준 4.5:1 **미달**입니다.

| 줄 | 무엇 |
| --- | --- |
| **216** | **`{f.label}` — 서식 칸 이름.** 이 화면에서 가장 중요한 글자입니다 |
| 179 | 제출처 보조문 |
| 207 | 「n칸 · 저희가 채운 값 m」 |
| 225 · 253 · 267 · 269 · 277 · 283 | 「이 기기에선 복사 안 됨」·「서식에 인쇄돼 있는 문구입니다」·접수 칸 이름·「적지 않음」·「수수료 없음」·2쪽 안내 |

**✅ 적용하면서 `ink-3`·`ink-4` 로 옮겼습니다.** `aria-hidden` 글리프 셋은 그대로 뒀습니다.

> **같은 위반이 두 번째입니다.** 2026-08-19 에 45곳을 고쳤는데 새 시안에서 되살아났습니다 —
> **다음 프롬프트에 「`icon` 은 아이콘 전용」을 명시적으로 넣어야 합니다.**

### 임의 `oklch` 열다섯 곳 — **문제 아님. 집안 관행입니다**

`oklch(0.697 0.16 258.2/…)` 는 `--pii`, `oklch(0.305 0.013 267.1/…)` 는 `--hairline` 계열,
`oklch(0.77 0.117 70.9/…)` 는 `--deadline-urgent` 의 **투명도 변형**입니다.

**`plan.tsx`·`page.tsx` 가 이미 같은 표기를 씁니다.** 색 자체는 토큰으로 쓰고
(`text-pii`·`border-hairline`), **알파를 섞은 변형만** raw 로 적는 것이 지금 코드의 관행입니다 —
토큰에 이미 알파가 들어 있어서(`--hairline` 은 `/52%`) 투명도 수식어를 겹쳐 쓰면 값이 어긋납니다.

**시안을 여기 맞춰 고치면 오히려 이웃 파일과 달라집니다.** 그대로 둡니다.

> ⬜ **다만 팔레트를 고칠 때 이 변형들이 안 따라옵니다.** 저장소 전체의 문제이고
> 이 화면만의 문제가 아니라, 알파 변형을 토큰으로 승격할지는 따로 볼 일입니다.

## 계약에 걸리는 미결 — 사람이 정합니다

**아래는 적용 뒤에도 남습니다.** 코드로 못 닫는 것들입니다.

> ([데이터 모델](../../../../spec/backend/08-16-data-model.md) §11.1).

| 무엇 | 왜 정해야 하나 |
| --- | --- |
| **`localStorage` 가 `case-purger` 밖입니다** | 「복사됨」을 기기에 남깁니다. [ADR-016](../../../../decisions/016-retention-and-datastore.md)이 **세 층이 같은 날 함께 사라진다**고 정했는데 이건 넷째 자리입니다. 값이 아니라 **어느 칸을 옮겼는지**라 위험은 낮지만, **파기 대상에 안 들어 있습니다** |
| `GET …/doc-guide` | [API 계약](../../../../spec/common/08-14-api.md)에 없습니다. `SECTIONS` 가 지금은 목 데이터입니다 |
| 신청사유 요약문 | 대화에서 정리한 문장을 그대로 신청서에 옮기게 합니다. **거짓 신청 경고가 붙는 칸**이라 문구를 사람이 봐야 합니다 |
