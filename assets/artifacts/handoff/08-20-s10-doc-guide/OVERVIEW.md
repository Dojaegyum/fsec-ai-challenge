# Handoff: S-10 「서류 기재 안내」

## Overview
`/c/{token}` 본문 열(≈770px)을 채우는 뷰. 피해구제신청서를 **만들지 않고**, 법정 서식(별지 제1호서식)의 칸과 아는 값을 짝지어 **눌러 복사**하게 합니다. 대상 저장소 `Dojaegyum/fsec-ai-challenge`. 3열 셸(T0 288 | 본문 | 350)은 기구현 전제 — 이 화면은 시트가 아니고 딤을 깔지 않습니다.

## 시안에서 정한 것 (스펙의 미결 3건)
1. **접는 단위 = 서식 구획 그대로** (피해자 / 송금·이체 내역 / 사기이용계좌 / 환급금 계좌 / 신청사유 / 말미). 사용자가 서식 실물과 1:1 대조 가능. 기본 펼침: 피해자 + 송금·이체 내역
2. **오른쪽 350px 열 = 제출 WS 패널(부산물: 접수증) + 대응 비서 유지** — 폼을 채우다 막히는 질문("개설점포가 뭐예요?")이 이 화면의 주 챗 사용처
3. **빈칸이 초라해 보이지 않게**: 모름 칸도 서식 칸 이름 + 점선 슬롯 + 보조문("통장 표지에 있습니다")으로 **안내 자체가 값** — 빈 줄이 없음. 구획 헤더에 「n칸 · 저희가 채운 값 m」 카운트
