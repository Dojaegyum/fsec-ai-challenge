## 무엇이 들어가나
- 서식 구획 6개 접기(기본 펼침 2) + 접수(은행 기재, 흐림) + 첨부서류 + 2쪽(낮은 무게)
- 값 상태 넷: confirmed(복사) / unread(복사 + 앰버 ! 「확인해 주세요」) / unknown(점선 「직접 적으셔야 합니다」) / staff(흐림·비활성)
- 눌러 복사: display는 끊어 보여주고 clipboard에는 raw(끊지 않은 원문). 복사됨 ✓는 localStorage(`finally:doc-copied:{caseId}`)에 기억 — 은행 앱 갔다 와도 유지. 헤더에 「옮겨 적음 n / m」
- 제출처 카드: `submitTarget` 서버 값 슬롯 — 화면이 단정하지 않음 (KB국민·NH농협 = 영업점 서면, 2026.08.20 확인 기준)
- 거짓 신청 경고: 말미 구획 안, 「서식에 인쇄돼 있는 문구입니다」 프레임 + 「사실대로 적으셨다면 해당하지 않습니다」 — 빼지 않되 겁주지 않음
- 다른 기기(restored=false): PII 값이 가려진 칩으로, 「이 기기에선 복사 안 됨」 + 고장 아님 안내. 날짜·은행명은 어디서든 복사
