## 이 핸드오프가 답한 것 둘

**둘 다 우리가 「시안이 없어 못 정한다」고 올려 둔 자리입니다.**

| 물음 | 답 |
| --- | --- |
| **기한만 모아 보여주는 화면을 둘 것인가** | **두지 않습니다.** `deadline-viewer` 는 **배지 3변형**만 만듭니다. 목록을 두면 히어로·단계 행과 어긋날 수 있는 **두 번째 정본**이 생깁니다 |
| **공고 대기 두 달을 어떻게 그릴 것인가** | **달력 앵커**(시작·지금·만료 예정). D-n·퍼센트 없음. 1b 의 47% 진행 스트립은 카운트다운으로 읽혀 **폐기** |

## 배지 세 변형 — 2b

| 변형 | 색 | 무엇 |

| 사용자 기한 | 앰버(`--deadline-urgent`) | 「8월 20일까지 · D-2」 — **D-day 는 여기에만** |

## 미결이었던 셋 — 2026-08-23 에 사람이 정했습니다

| 무엇 | 정한 것 | 그래서 |
| --- | --- | --- |
| **`--horizon` 에 뜻을 실어도 되나** | ✅ **싣는다** | 토큰의 뜻을 「장식 + **제도가 흐르는 시간**」으로 넓혔습니다 → [ADR-048](../../../../decisions/048-horizon-carries-meaning.md). 조건 둘 — 그래픽은 전부 `aria-hidden`, 글자는 색 없이도 뜻이 설 것 |
| **`anytime` 의 기호** | ⚠️ **`◇`** — §S-07 표대로 | **이 자리에서 시안이 졌습니다.** 기호가 정보를 한 겹 더 싣는 쪽입니다. 코드를 고쳤고 시안은 어긋난 채 남습니다 — **다음 핸드오프에 반영을 요청합니다** |
| **공고 시작일·진행 위치를 누가 주나** | ✅ **서버가 준다** | §3.7 에 `starts_at`·`elapsed` 두 칸을 넣기로 확정. **서버는 아직 미구현**이라 픽스처가 견본을 먹입니다 |

## 이번에 안 한 것

- **헤더 칩**(`국민은행 계좌이체` · `지급정지 완료` · `피해구제 신청까지 D-2` · `가족에게 링크 보내기`)은
  셸(`page.tsx`)의 몫이라 이 작업에서 건드리지 않았습니다.
- **히어로 스트립의 D-day 박스**는 아직 상수입니다 — `days_left` 가 계약에 들어오면
  그 자리가 배지가 됩니다.
- 「통지·우편을 올리시면 읽어드립니다」 버튼은 **아직 아무 데도 가지 않습니다.**
