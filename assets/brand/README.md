# brand — FinAlly 브랜드 자산

원본 시트 한 장에서 요소별로 잘라낸 것입니다. **정본은 시트**이고, 나머지는 거기서 파생된 사본입니다.
시트가 새로 오면 전부 다시 뽑습니다.

| 파일 | 무엇 |
| --- | --- |
| `08-16-brand-sheet.png` | **원본 시트** (1536×1024). 로고·아이콘·태그라인·앱 목업이 한 장에 |

**태그라인** — 영문 `YOUR FINANCIAL ALLY`(로고에 함께 그려져 있음), 한글 「금융 위기의 순간, 당신의 편이 되어 함께합니다.」
네 기둥은 보호(Protect) · 동행(Ally) · 안내(Guide) · 지원(Support)입니다.

> ⚠️ **시트의 한글 태그라인이 「금융 위기의 손간」으로 적혀 있습니다** — 「순간」의 오타로 보입니다.
> 원본이라 손대지 않았습니다. 시트를 다시 뽑을 때 확인하세요.

> ⬜ **흰색 가로 로고가 없습니다.** `logo/`는 전부 검정 아트워크인데 제품은 다크 전용이라,
> 지금은 CSS `invert`로 뒤집어 씁니다. 흰색 추출본이 오면 그 처리를 지웁니다.
> 가로 로고에는 태그라인이 함께 그려져 있어 **28px 높이에서 태그라인이 뭉개집니다** —
> 헤더에는 `symbol-mark` + 텍스트 워드마크를 씁니다.

## 어떤 걸 언제 쓰나

### `logo/`

| 파일 | 쓰는 곳 |
| --- | --- |
| `logo-primary.png` | 발표 표지, 랜딩 히어로 — 심볼 + 워드마크 + 태그라인 |
| `logo-horizontal.png` | 헤더·푸터처럼 가로로 좁은 자리 |
| `symbol-mark.png` | 심볼만 필요할 때. favicon·앱 아이콘의 원본 |

### `icon/` — 시트에 들어 있던 아이콘 변형

`icon-rounded-dark`(검정 라운드) · `icon-rounded-light`(흰 라운드) · `icon-circle-dark` ·
`icon-circle-light` · `icon-frame-light`. **배경이 이미 그려져 있는 시안**이라, 실제 파비콘은
아래 `favicon/`을 씁니다.

### `favicon/` — 실사용 규격 (심볼에서 생성, 배경 투명)

| 파일 | 쓰는 곳 |
| --- | --- |
| `favicon.ico` | 16·32·48 멀티 사이즈. 구형 브라우저·기본 탭 아이콘 |
| `favicon-16 … 512.png` | 탭·북마크·PWA 매니페스트 |
| `favicon-180.png` | iOS 홈 화면 (`apple-touch-icon`) |
| `favicon-192.png` · `favicon-512.png` | Android·PWA 매니페스트 |
| `*-white.png` | **어두운 배경용.** 심볼이 검정 단색이라 다크 배경에서는 이걸 씁니다 |
| `symbol-square.png` / `-white.png` | 정사각 원본(여백 12%). 다른 크기가 필요하면 여기서 뽑습니다 |

## 알고 있어야 할 한계

- **16px에서는 뭉개집니다.** 사람 둘 + 방패 + 방패 안 문양까지 세 겹이라 브라우저 탭 크기에서
  검은 덩어리가 됩니다. **32px부터 읽힙니다.** 파비콘까지 또렷하게 하려면 방패만 남긴
  단순화 심볼이 따로 필요합니다.
- **래스터(PNG)입니다.** 확대하면 깨지므로 큰 인쇄물·대형 화면에는 한계가 있습니다.
  심볼만이라도 **SVG로 다시 그리면** 여기 있는 모든 규격을 거기서 뽑을 수 있습니다.
- **투명 배경은 바깥 여백만** 뺐습니다(방패 안쪽 흰 문양은 그대로). 경계에 흰 잔상이
  아주 옅게 남을 수 있습니다.

## 앱에 반영하려면

여기 파일은 **원본이라 앱이 직접 쓰지 않습니다** (→ [assets/README.md](../README.md)).
Next.js에 넣으려면 `src/app/favicon.ico`를 교체하고, 나머지 규격은 `src/public/`에 복사한 뒤
매니페스트·`<link rel="apple-touch-icon">`에 연결합니다. **아직 반영하지 않았습니다.**

## 출처

브랜드 시트는 생성형 이미지 도구로 만든 초안을 사람이 검수한 것입니다.
초판에는 로고타입이 `FinAly`(l 하나)로 잘못 나와 폐기했고, 지금 시트가 `FinAlly`로 고친 판입니다
— 이름 표기 규칙은 [ADR-002](../../decisions/002-project-name.md).
