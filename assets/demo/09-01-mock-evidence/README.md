### 부산물 셋 — 절차가 남기는 것 (2026-09-06 추가)

위 셋은 **사건이 시작될 때** 올리는 증거입니다. 아래 셋은 **절차를 밟고 나서 생기는 것**이라
시작 화면의 칩이 아니라 **워크스페이스의 증빙 자리**에 올립니다. 생성기는 [make_mock_receipts.py](make_mock_receipts.py),
대본은 같은 `script.json` 의 `receipt_relief`·`receipt_112`·`notice_freeze` 입니다.

| 파일 | 무엇 | 어느 단계 · 무엇을 보나 |
| --- | --- | --- |
| `receipt-relief.png` | 피해구제 신청 접수증 | 「신청서류를 금융회사에 제출합니다」 · 통장묶기의 「이의제기 접수증」. 판정기가 **「접수번호」 자리 뒤의 번호**를 봅니다 (completion-checker L2 · ADR-077) |
| `receipt-112.png` | 112 신고 접수 안내 문자 | 「112에 신고합니다」. **공공기관 이름(경찰청 · `org-public.json`)** 과 「사건접수번호」 |
| `notice-freeze.png` | 채권소멸절차 개시 공고 통지 | 피해자 트랙의 「공고합니다」 단계 증빙(「공고번호」) · **통장묶기 트랙의 공고일** — `slot-extractor` 가 「공고일 2026.09.03」을 뽑아 확인받고, 그 날부터 **2개월**이 이의제기 기한으로 섭니다 (ADR-071 · ADR-054) |

**왜 셋이 따로 필요한가** — 처음 셋은 판정기에 전부 「접수번호·기관명 없음」으로 떨어지도록
설계돼 있습니다(이체 캡처는 접수증이 아닙니다). 접수번호를 손으로 적는 L1 은 그것 없이도 되지만,
**파일로 완료하는 L2 와 통지문에서 공고일을 뽑는 길**은 이 셋이 있어야 시연할 수 있습니다.
문서 모양은 어느 기관의 실제 서식도 흉내 내지 않았고, 아래에 「시연용 예시」 줄이 박혀 있습니다. 계좌번호 `110-234-567890` · 금액 3,200만원 ·
국민은행이 **셋에 모두** 나옵니다 — 같은 값에 같은 이름표(`[계좌-1]`)가 붙는지 보는 자리입니다.

## 값은 전부 임의입니다

사람 이름·계좌번호·전화번호·사건번호·거래번호 어느 것도 실재하지 않습니다.
**주민등록번호는 일부러 넣지 않았습니다** — 동의 화면이 「주민등록번호는 받지 않습니다」라고
말하고 있어, 시연 자료가 그 약속과 어긋나면 안 됩니다.

수법은 지어낸 것이 아니라 [research/07 §2.2](../../../docs/research/07-학습데이터-조사.md)가
정리한 실제 특징을 따릅니다 — 검찰 사칭 · 수사 목적 통화임을 강조 · 사건 내용을 구체적으로
설명 · 전문용어 사용. 여기에 실제 피해를 키우는 세 대목을 더 넣었습니다: 가족에게도
말하지 말라는 비밀 유지 요구, 말하면 구속된다는 압박, **창구를 피하고 앱으로 하라는 유도**
(은행 직원이 개입할 기회를 없앱니다).

## 다시 만들려면

```
services/transcriber/.venv/bin/python make_mock.py      # edge-tts · ffmpeg · PIL 이 필요합니다
cp call.wav messages.png transfer.png ../../../src/public/demo/

python make_mock_receipts.py                            # 부산물 셋 — PIL 만 있으면 됩니다
cp receipt-relief.png receipt-112.png notice-freeze.png ../../../src/public/demo/
```

**앱이 서빙하는 사본은 `src/public/demo/`** 입니다 — 원본과 사본을 같은 곳에 두지 않는
[RFC-001](../../../rfc/001-repo-structure.md)의 규칙 그대로입니다.

## ⚠️ 전사가 여기서 잘 된다고 실제에서도 그렇지 않습니다

TTS 합성음은 실제 통화보다 발음이 또렷합니다
([research/09](../../../docs/research/09-로컬모델-PII인식-실측.md)의 같은 경고).
**성능 수치를 이 파일로 재지 마세요** — 그건 `assets/datasets/` 의 측정 원본이 할 일입니다.

측정해 둔 값: `faster-whisper medium` · CPU · int8 · beam 5 로 앞 45초를 전사하는 데
**97초**(2.2배) 걸렸고, 사람 이름 하나가 「김도현 → 김도연」으로 바뀌었을 뿐 나머지는
그대로 나왔습니다. 숫자는 「구십일년 삼월생」이 `91년 3월생`으로, 사건번호가 `2026형제38...`
으로 **자릿수 표기로 돌아옵니다** — 계좌번호가 가려지려면 이게 되어야 합니다.
