## 무엇이 들어 있나

| 파일 | 무엇 | 어느 슬롯 |
| --- | --- | --- |
| `call.wav` | 검찰 사칭 통화 (약 3분 30초 · 8kHz μ-law) | 통화 녹음 |
| `messages.png` | 통화 전후의 문자 화면 | 문자·메신저 캡처 |
| `transfer.png` | 은행 앱 이체 완료 화면 | 이체 내역 |

**셋이 한 사건입니다.** 문자로 접촉해서 → 통화로 압박하고 → 문자로 계좌를 확정해 →
이체를 받고 → 추가를 요구하다 끊깁니다. 계좌번호 `110-234-567890` · 금액 3,200만원 ·
국민은행이 **셋에 모두** 나옵니다 — 같은 값에 같은 이름표(`[계좌-1]`)가 붙는지 보는 자리입니다.

## 값은 전부 임의입니다

사람 이름·계좌번호·전화번호·사건번호·거래번호 어느 것도 실재하지 않습니다.
**주민등록번호는 일부러 넣지 않았습니다** — 동의 화면이 「주민등록번호는 받지 않습니다」라고
말하고 있어, 시연 자료가 그 약속과 어긋나면 안 됩니다.

수법은 지어낸 것이 아니라 [research/07 §2.2](../../../docs/research/07-학습데이터-조사.md)가
정리한 실제 특징을 따릅니다 — 검찰 사칭 · 수사 목적 통화임을 강조 · 사건 내용을 구체적으로
설명 · 전문용어 사용. 여기에 실제 피해를 키우는 세 대목을 더 넣었습니다: 가족에게도
말하지 말라는 비밀 유지 요구, 말하면 구속된다는 압박, **창구를 피하고 앱으로 하라는 유도**
(은행 직원이 개입할 기회를 없앱니다).

## 다시 만들려면

```
services/transcriber/.venv/bin/python make_mock.py      # edge-tts · ffmpeg · PIL 이 필요합니다
cp call.wav messages.png transfer.png ../../../src/public/demo/
```

**앱이 서빙하는 사본은 `src/public/demo/`** 입니다 — 원본과 사본을 같은 곳에 두지 않는
[RFC-001](../../../rfc/001-repo-structure.md)의 규칙 그대로입니다.

## ⚠️ 전사가 여기서 잘 된다고 실제에서도 그렇지 않습니다

TTS 합성음은 실제 통화보다 발음이 또렷합니다
([research/09](../../../docs/research/09-로컬모델-PII인식-실측.md)의 같은 경고).
**성능 수치를 이 파일로 재지 마세요** — 그건 `assets/datasets/` 의 측정 원본이 할 일입니다.

측정해 둔 값: `faster-whisper medium` · CPU · int8 · beam 5 로 앞 45초를 전사하는 데
**97초**(2.2배) 걸렸고, 사람 이름 하나가 「김도현 → 김도연」으로 바뀌었을 뿐 나머지는
그대로 나왔습니다. 숫자는 「구십일년 삼월생」이 `91년 3월생`으로, 사건번호가 `2026형제38...`
으로 **자릿수 표기로 돌아옵니다** — 계좌번호가 가려지려면 이게 되어야 합니다.
