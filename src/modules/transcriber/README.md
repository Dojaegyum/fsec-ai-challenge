## 이 자리가 왜 위험한가

```
file-sender(브라우저) → pii-masker(브라우저) → transcriber(여기) → pii-tokenizer(경계)
                                                    ↑
                                       원문이 서버에 존재하는 유일한 지점
```

[ARCHITECTURE.md](../../../ARCHITECTURE.md) §6 이 STT·OCR 행에 **「경계 이전 ⚠️」**을 달고
*"이 자리가 경계의 가장 약한 고리입니다"* 라고 적었습니다.

녹음에는 계좌번호가 음성으로 들어 있고 이체내역 캡처에는 숫자가 그대로 찍혀 있습니다.
**원격 API 를 고르는 순간 그 원본이 밖으로 나갑니다.**

**그래서 이 모듈은 제품을 고르지 않습니다.** 읽는 도구를 인터페이스로 선언하고 밖에서
받습니다 ([ADR-028](../../../decisions/028-runtime-and-module-shape.md)) — `pii-tokenizer` 가
판별 모델을 같은 방식으로 다룬 것과 같습니다. **무엇을 끼울지는 조립부의 결정이고,
그 결정이 곧 경계 정책입니다.**

## 안 하는 것

| 안 합니다 | 왜 |
| --- | --- |
| **저장** | `evidence.transcript_masked` 는 **토큰화된 것만** 받습니다 → [09](../../../spec/backend/08-16-data-model.md) §3 |
| **토큰화** | 경계는 `pii-tokenizer` 하나입니다. 여기가 두 번째 경계가 되면 우회할 자리가 둘이 됩니다 |
| **값 다듬기** | 「삼백만원」→「3000000」·「어제」→ 날짜. 아래 「고치지 않습니다」 |
| **누가 사기범인지 정하기** | 녹음 안에 그 근거가 없습니다. 아래 「화자를 이름표로만 냅니다」 |
| **꺾쇠 escape** | `prompt-builder` 의 몫입니다. 두 곳에서 하면 화면에 `&lt;` 가 보입니다 |
| **덜 읽힌 것을 에러로 올리기** | 아래 「덜 읽힌 것은 정상 경로입니다」 |
| **「아직 없다」를 스스로 표현하기** | 조립부의 일입니다. 아래 「미설정을 전사 실패로 덮지 않습니다」 |

## 덜 읽힌 것은 정상 경로입니다

한 줄도 못 읽어도, 화자를 못 갈라도, 신뢰도를 못 받아도 **던지지 않습니다.**
[CLAUDE.md](../../../CLAUDE.md) 불변 규칙 5 가 *"「모름」은 실패가 아니다"* 로 정했고,
[10-errors.md](../../../spec/backend/08-16-errors.md) §2 가 전사를 *"배경 작업이라 여유가
있습니다"* 로 두었습니다.

**대신 무엇을 못 했는지는 숨기지 않습니다** — `shortfalls` 에 실려 나갑니다.

| 값 | 뜻 | 무엇이 안 되나 |
| --- | --- | --- |
| `empty` | 읽어낸 줄이 없다 | — |
| `no_speakers` | 화자를 못 갈랐다 | §3.3 의 `speaker` 가 전부 `null` |
| `no_confidence` | 판독 신뢰도가 없다 | **[ADR-038](../../../decisions/038-transcript-confirm.md) 의 확인 화면을 못 연다** |
| `no_pieces` | 낱말·줄 조각이 없다 | 확인 화면이 줄 단위로만 열린다 |
| `no_anchors` | 원본의 자리가 없다 | **원본 조각을 나란히 못 띄운다** |
| `no_layout` | 말풍선 좌·우를 못 세웠다 | 캡처의 화자가 `null` |
| `not_applicable` | 옮길 것이 없다 (`kind: 'text'`) | — |

## 던지는 것 둘

| 언제 | 무엇 |
| --- | --- |
| 읽는 도구 **호출 자체**가 실패 | `IngestError` — `INGEST_FAILED` · 422 · 재시도 1회 → [10](../../../spec/backend/08-16-errors.md) §2 |
| 도구·저장소가 **아직 안 붙음** | 그 예외를 **그대로** 올립니다 (아래) |

### 미설정을 전사 실패로 덮지 않습니다

`lib/not-configured.ts` 가 *"미설정과 장애를 같은 코드로 내지 않습니다. 섞으면
`Retry-After: 10` 이 붙어 사용자가 10초마다 헛되이 다시 누릅니다"* 라고 적었습니다.

그래서 이 모듈은 **「도구가 없다」는 예외를 스스로 만들지 않습니다.** `stt`·`ocr` 을
필수 자리로 두고, 조립부가 부르면 터지는 대역을 끼웁니다. 그 예외가 `AppError` 이면
**감싸지 않고 그대로 올립니다.**

`pii-tokenizer` 의 판별 모델이 `null` 이어도 되는 것과 다릅니다 — 그쪽은 없어도 1차
정규식으로 경계가 서지만, **여기는 대신할 것이 없습니다.**

## 화자를 이름표로만 냅니다

`speaker` 는 `"A"`·`"B"` 이고 **먼저 말한 쪽이 `A`** 입니다.

**누가 사기범인지는 정하지 않습니다.** 수신 통화면 사기범이 먼저 말하고 발신 통화면
피해자가 먼저 말하는데, **녹음 파일 안에 어느 쪽인지가 없습니다.** 여기서 정하면 근거
없는 판정이 되고 그 값이 `case-reader` 의 수법 판별까지 흘러갑니다.

엔진이 매긴 구분값(`0`·`SPEAKER_00`·이름)을 그대로 쓰지 않는 것은, 제품마다 모양이
달라 화면과 프롬프트가 제품에 묶이기 때문입니다.

## 구조가 곧 격리입니다

**한 덩어리 문자열로 내보내지 않습니다.**

업로드된 내용은 지시가 아니라 자료이고([CLAUDE.md](../../../CLAUDE.md) 불변 규칙 4),
`prompt-builder` 가 `{ speaker, text }` 를 받아 비신뢰 블록으로 감싸며 꺾쇠를 막습니다
→ [13-system-prompt.md](../../../spec/backend/08-17-system-prompt.md) 「자료 블록의 모양」.

한 덩어리로 내면 화자 구분이 사라져 **사기범이 통화 중에 읽어 준 문장과 피해자의 진술이
한 줄에 섞입니다.**

## 고치지 않습니다

실측이 전사에서 값이 깨지는 것을 확인했지만, **전사문 자체를 고치면 세 가지가 깨집니다.**

```
원본   3333-01-2345678        (계좌번호)
전사   "3333년 1월 23일 35678로"
```

1. 사용자가 [확인 화면](../../../decisions/038-transcript-confirm.md)에서 볼 **원본이 사라집니다**
2. `F-04` 가 근거로 인용할 대목이 **어긋납니다**
3. **받은 자료가 우리가 고쳐 쓴 것이 됩니다** (불변 규칙 4)

정규화가 필요하면 전사문 **옆에** 붙여야 하고, 그건 이 모듈의 일이 아닙니다.

## 판단이 필요했던 자리

| 자리 | 어떻게 했나 | 왜 |
| --- | --- | --- |
| **신뢰도를 몇 개로 낼까** | **둘로 갈랐습니다** — 판독(`Piece.confidence`)과 화자(`Line.speakerConfidence`) | 「잘 들었나」와 「누가 말했나」는 다른 축입니다. 계좌번호를 사기범이 불러 준 것인지 피해자가 되읊은 것인지가 슬롯의 뜻을 바꿉니다. **의미 신뢰도(`case_slot.confidence`)는 여기서 안 냅니다** — 그건 `slot-extractor` 가 모델에게 물어 받는 자기신고값입니다 |
| **자리가 없는 줄을 버릴까** | **안 버립니다.** `at` 를 `null` 로 두고 `no_anchors` 를 실습니다 | 글자가 산출물이고 자리는 그것을 확인시키는 것입니다. 자리 때문에 글자를 버리면 주객이 뒤집힙니다 |
| **끝 시각이 없으면** | 시작과 같게 둡니다 | §3.3 이 필수로 둔 것은 `start_ms` 하나입니다. 끝을 못 받았다고 줄을 버리면 계약이 요구하는 값까지 사라집니다 |
| **말풍선 좌·우를 어떻게 가를까** | **좌표 규칙.** 두 무리가 충분히 벌어질 때만 | 어떤 판독기도 「왼쪽이 상대」를 모릅니다. **애매하면 안 가릅니다** — 틀린 화자를 붙이면 사기범이 한 말이 피해자가 한 말로 기록됩니다 |
| **범위 밖 신뢰도** | 버리고 `null` | `1.5` 를 두면 「신뢰도 낮은 것」을 고르는 비교가 조용히 틀립니다 |
| **`kind: 'text'`** | 빈 결과 + `not_applicable`. **에러 아님** | 옮길 것이 없는 것은 실패가 아닙니다. 부르는 쪽이 토큰화만 거쳐 저장하면 됩니다 |
| **파일 바이트를 받을까** | **안 받습니다.** 읽기용 주소만 넘깁니다 | Vercel 함수 본문 한계. 업로드가 presigned 인 이유와 같습니다 → [08](../../../spec/common/08-14-api.md) §3.2 |
| **실패 기록에 무엇을 담을까** | **어디서·무엇이만.** 원인 문자열과 읽기 주소는 안 담습니다 | 판독기 오류 본문에 파일 내용이 섞여 올 수 있고, 읽기 주소는 유효기간이 붙은 접근 수단입니다 |
