# work-handler

**어느 작업 패널을 열지 정하고, 그 패널을 맡습니다.** 층 C — 브라우저에서만 돕니다.

계약은 [워크스페이스 패널](../../../spec/frontend/08-17-workspace-panels.md)과
[API 계약](../../../spec/common/08-14-api.md) §3.6·§3.9이고, 근거는
[ADR-023](../../../decisions/023-frontend-module-names.md)(층 C · 판정과 렌더를 한 모듈로)·
[ADR-024](../../../decisions/024-step-action-and-url.md)(`body.action` 신설)입니다.

```ts
import { applySignal, openStep, panelRule, exitFor } from "@/modules/work-handler";

// 챗 한 턴이 끝나면
const next = applySignal(current, answer.referenced_steps, plan.steps);

// 사용자가 보드에서 단계를 누르면 — 같은 자리로 들어옵니다
const next = openStep(current, stepId, plan.steps);
```

## 시그널

```
챗 응답의 referenced_steps
   ↓  아직 안 끝난 것만 (done_verified · skipped 제외)
   ↓  그중 seq 가 가장 작은 것 하나
   ↓
그 단계의 body.action 으로 패널을 연다
```

**모델이 패널을 고르지 않습니다.** 모델은 이미 내고 있는 `referenced_steps`만 내고,
패널은 여기서 규칙으로 정합니다 — 「모델은 도구를 부르지 않는다」를 그대로 지킵니다.

| 조건 | 동작 |
| --- | --- |
| 남은 것이 있음 | 그 단계로 **패널을 바꾼다** |
| **남은 것이 없음** | **패널을 그대로 둔다. 닫지 않습니다** |
| 보드에서 직접 누름 | 같은 패널이 열립니다 — **두 경로가 한 곳으로** |

**왜 안 닫는가** — `referenced_steps`는 "감사합니다" 같은 발화에서 비어 있습니다.
그때 패널이 사라지면 **사용자가 적고 있던 접수번호를 잃습니다.**

## 절대 하지 않는 것

- **판정을 렌더와 섞기.** 둘을 한 모듈로 합친 대가라, 경계가 이름이 아니라
  **모듈 안의 규칙**으로만 남습니다. 섞이면 "왜 이 패널이 떴나"를 짚을 수 없습니다.
- **`actor`·`channel`·`required_artifact`로 유형을 추론하기.** 서버가 준 `action`을 그대로 씁니다.
- **시그널이 패널을 닫기.** 닫는 것은 사용자만 합니다.
- **`WS-download` 밖에서 원문 펼치기.** 전체 복원이 허용된 유일한 작업 패널입니다.

## 판단이 필요했던 자리

| 무엇 | 어떻게 | 왜 |
| --- | --- | --- |
| **모르는 `action`** | **`null`** — 후보에서 빼고 다음 `seq`로 | `WS-read`로 떨어뜨리면 **해야 할 일을 안 해도 되는 것처럼** 보입니다 |
| **밀려난 단계** | `onSkipped`로 알립니다 | 조용히 넘어가면 "왜 이 패널이 떴나"를 짚을 수 없습니다 |
| **연락처와 주소가 둘 다 있으면** | **연락처가 앞섭니다** | 기관을 아는 쪽이 더 정확합니다 |
| **둘 다 없으면** | `{ kind: "none" }` | **그때도 절차는 나갑니다.** 화면이 「어느 은행인지」를 되물으면 됩니다 |
| **유형별 규칙을 어디 두나** | `panel.ts`의 표 하나 | 컴포넌트에 흩뿌리면 패널이 늘 때마다 어디를 봐야 할지 알 수 없습니다 |

## 아직 아닌 것

- ⬜ **렌더.** 지금은 판정만 서 있습니다. 화면이 설 때 같은 폴더에 붙습니다 —
  **판정과 렌더를 섞지 않는 것**이 이 모듈의 규칙입니다.
- ⬜ **`WS-visit`에서 돌아왔는지 감지.** 탭 복귀로 물어볼지, 사용자가 올릴 때까지 기다릴지 미정.
- ⬜ **`WS-download`가 가리킬 초안.** `doc-builder`(F-08)가 P1이라 엔드포인트 계약이 없습니다.
- ⬜ **한 단계에 유형이 둘일 때**(통화 → 받아적기)를 한 패널의 단계로 볼지 두 패널로 볼지.
