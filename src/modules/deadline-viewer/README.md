## 기한 목록 화면은 만들지 않습니다

시안 2b 의 판단입니다 — **목록을 두면 히어로·단계 행과 어긋날 수 있는 두 번째 정본이
생깁니다.** 세 가지 일을 각각 다른 자리가 맡습니다:

| 무엇 | 어디가 맡나 |
| --- | --- |
| 지난 기한 보존 | **단계 행** (지우지 않고 남습니다) |
| 본 기한 / 유예 분리 | **배지 병치** (`DeadlinePair`) — 합치지 않습니다 |
| 환급 비카운트다운 | **공고 대기 카드** (`WaitCard`) |

## 배지 셋 — 그 밖의 변형을 만들지 마세요

| 변형 | 색 | 무엇 |
| --- | --- | --- |
| `user` | 앰버 | 「8월 20일까지 · D-2」 — **D-day 는 여기에만** |
| `passed` | 중립 | 「본 기한 8월 20일 · 지남」 — 지우지 않습니다 |
| `system` | 중립 | 「채권소멸공고 10월 30일」 — 날짜만, D-day 없음 |

**환급에는 배지가 없습니다.** 날짜를 약속하지 않는 자리라 「통지가 오면 알려드립니다」
한 줄이 대신합니다 — 없는 기한을 지어내지 않습니다.

## 왜 D-day 가 안 뜨나

`days_left` 가 응답에 없으면 **일부러 안 그립니다** — 날짜만 나갑니다.
`due_at` 에서 화면이 직접 세면 사용자 기기의 날짜가 틀렸을 때 기한을 놓칩니다
([기한 규칙](../../../spec/common/08-16-deadline-rules.md)).

**서버는 지난 기한에 `days_left` 를 싣지 않습니다**(2026-08-23 확정 · §3.7) —
지난 것은 `status: "missed"` 하나로 오고, 표시는 「본 기한 8월 20일 · 지남」 배지가 맡습니다.
**음수가 와도 그리지 않습니다** — 시안에 「D+3」 이라는 표시가 없습니다.

### 「8월 20일」은 세는 것이 아닙니다

`dueLabel` 은 서버가 준 시점 하나를 **표기만 바꿉니다.** 시계를 읽지 않고
(`Date.now()` 없음), 기기의 시간대 설정도 따르지 않습니다 — `Asia/Seoul` 로 못 박습니다.
`transcript-viewer` 가 `start_ms` 를 「00:12」로 바꾸는 것과 같은 성격입니다.

## 판단이 필요했던 자리

| 무엇 | 어떻게 | 왜 |
| --- | --- | --- |
| **`days_left` 가 없을 때** | 날짜만 그리고 D-day 를 뺍니다 | 「D-?」 자리표시를 두면 나중에 그걸 채우려고 화면이 세게 됩니다 |
| **음수 `days_left`** | 그리지 않습니다 | 계약상 오지 않는 값입니다. 와도 「D+3」 을 지어내느니 날짜만 보이는 쪽이 낫습니다 |
| **`due_at` 을 못 읽을 때** | 배지를 아예 안 그립니다 | 「Invalid Date」가 화면에 나가는 것보다 낫습니다 |
| **모르는 `kind`** | `primary` 로 둡니다 | 버리면 기한 목록이 조용히 비고, 사용자는 놓친 줄도 모릅니다 |
| **지난 기한** | 목록에 남기고 중립 배지 | 본 기한을 넘겨도 유예 14일이 남아 있습니다 |
| **`days_left === 0`** | 「오늘」 | `D-0` 은 읽는 사람이 오늘인지 지났는지 모릅니다 |
| **`info` 에 `days_left` 가 와도** | **안 씁니다** | 두 달을 세면 매일 실망을 줍니다 |
| **앰버를 어디에** | `user` 에만 | `info` 까지 앰버면 두 달짜리 공고가 급한 일로 보입니다. **빨강은 어디에도 안 씁니다** |
| **공고 진행은 무슨 색** | `--horizon` | 앰버를 피하려고 고른 색입니다 → [ADR-048](../../../decisions/048-horizon-carries-meaning.md). 조건 둘이 붙습니다 — **그래픽은 전부 `aria-hidden`**, 글자는 색 없이도 뜻이 서야 합니다 |

## 아직 아닌 것

- ⏳ **`starts_at`·`elapsed`·`days_left` 를 서버가 아직 안 줍니다.** 셋 다 계약에
  **넣기로 확정**됐고(2026-08-23 · §3.7) 화면은 밖에서 받는 모양으로 서 있습니다 —
  지금은 `fixtures.ts` 의 견본을 먹습니다. 라우트가 서면 그 자리가 `fetch` 입니다.

  ⚠️ **서버에 부탁할 것 하나:** `days_left` 계산과 `status: "missed"` 전이를
  **같은 자리에서** 하세요. 갈라지면 지난 기한이 잠깐 「아직 안 지난 것」처럼 보이고,
  화면에는 그걸 알아챌 신호가 없습니다.
- ⬜ **히어로 스트립의 D-day 박스.** S-07 맨 위 `D-2` 는 아직 `plan.tsx` 의 상수입니다.
