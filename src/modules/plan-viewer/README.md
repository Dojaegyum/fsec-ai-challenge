# plan-viewer

타임라인·단계·상태 배지를 그립니다. **층 C(브라우저)** 입니다.

| | |
| --- | --- |
| 받는 것 | `GET /api/cases/{token}/plan` 의 `steps[]` ([API](../../../spec/common/08-14-api.md) §3.6) |
| 내놓는 것 | 타임라인·단계·배지 ([화면 설계](../../../spec/frontend/08-14-screens.md) §S-07) |
| 절대 하지 않는 것 | 사용자 체크만으로 완료 표시 · 조건부 단계 지우기 · **T0 를 다른 것에 종속시키기** |

## 번호를 아무 데나 붙이지 않습니다

우리 단계는 **절반이 순서가 없습니다.** 112 신고와 지급정지 요청은 동시에 하는 것입니다.
`body.after` 사슬에 있는 것에만 번호를 붙이고, 그 번호는 **사슬 안 위치**입니다 —
`step_seq`(10·20·25)를 그대로 보이면 「25번 다음이 30번」이 됩니다.

**`after`·`step_key` 는 §3.6 에 싣기로 확정됐습니다**(2026-08-23) — 서버는 아직 미구현입니다.
안 오면 전부 점으로 그립니다: 없는 순서를 지어내지 않고,
「번호가 붙은 것만 순서대로」 안내 줄도 **뜨지 않습니다.**

## 기한은 여기서 만들지 않습니다

`deadlineFor`·`hasDeadline` 을 **밖에서 받습니다.** 이 모듈이 기한을 조회하면
`deadline-viewer` 와 주인이 겹치고, **화면이 날짜를 세는 길**이 열립니다.

## 판단이 필요했던 자리

| 무엇 | 어떻게 | 왜 |
| --- | --- | --- |
| **`after` 가 없을 때** | **전부 점** — 번호를 안 붙입니다 | 없는 순서를 지어내면 사용자가 112 를 먼저 해야 한다고 읽습니다 |
| **선행인데 `seq` 가 클 때** | 위상 순서로 세고 동률만 `seq` | `seq` 로만 세면 번호가 역전됩니다 |
| **사슬이 순환일 때** | 남은 것 중 `seq` 최솟값부터. **던지지 않습니다** | 보드가 비면 「지금 뭘 해야 하나」가 사라집니다 |
| **모르는 `state`** | `todo` | 새 상태가 생겨도 보드가 비지 않아야 합니다 |
| **`unconfirmed` 의 어휘** | 기호는 `todo`, 태그만 **「증빙 대기」** | 「미확인」은 슬롯 배지(아직 모르는 정보)와 §S-08 전사 스팬이 이미 쓰는 말이라, 단계 상태까지 같은 말을 쓰면 **셋이 한 화면에서 섞입니다** (2026-08-23 확정) |
| **`todo`·`anytime` 의 기호** | `todo` 는 **빈 원**, `anytime` 은 **`◇`** | 시안은 둘 다 빈 원인데 §S-07 표는 `○`·`◇` 였습니다. **2026-08-23 사람이 `◇` 로 정했습니다** — 기호가 정보를 한 겹 더 싣는 쪽입니다. 시안은 이 자리에서 어긋난 채 남습니다 → [RFC-003](../../../rfc/003-design-handoff.md) |
| **머리·꼬리를 어디까지 가져오나** | 「할 일」 줄과 꼬리 문장까지 | 시안이 「할 일」과 순서 안내를 **한 줄**에 둡니다. 목록만 가져오면 사슬이 없을 때도 안내 줄이 화면에 남습니다 |
| **단계 사이에 끼우는 것** | `afterStep` 슬롯만 내주고 **무엇을 끼울지는 안 고릅니다** | 여기서 고르면 `plan-viewer` 가 기한·국면까지 알게 됩니다. 공고 대기 카드는 `deadline-viewer` 것입니다 |

## 아직 아닌 것

- ⬜ **히어로 스트립과 사건 진행 레일.** 아직 화면(`plan.tsx`)에 상수로 있습니다 —
  서버가 내려줄 값이 계약에 없습니다.
- ⬜ **부산물 한 줄(`◆ …`)의 출처.** 지금은 밖에서 `artifactFor` 로 받습니다.
  §3.6 의 `artifacts`·`required_artifact` 를 문장으로 옮기는 자리는 아직 없습니다.
