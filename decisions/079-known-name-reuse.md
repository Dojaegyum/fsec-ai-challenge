# ADR-079. 브라우저는 이미 아는 이름을 보내기 전에 그 이름표로 바꾼다 — 찾지는 않고, 서버는 우리 이름표 모양을 다시 가리지 않는다

## 맥락

[ADR-075](075-chat-mapping-handover.md) 로 챗이 만든 `[이름-1]` 의 짝이 볼트에 들어오게 됐지만,
**같은 이름을 다시 말하면 서버가 `[이름-2]` 를 새로 붙였습니다.**

| | 계좌 | 이름 |
| --- | --- | --- |
| 원문을 아는 쪽 | 브라우저 (1차가 가림) | **브라우저만** (짝을 봉해 맡긴 뒤) |
| 서버 장부 | 번호만 | 번호만 — 원문 없음 (불변 규칙 3) |
| 두 번째 언급 | 브라우저가 `[계좌-1]` 재사용 | 브라우저는 이름을 안 건드림 → 서버는 같은 값인지 모름 → **`[이름-2]`** |

경계 문서의 「같은 값이 다시 나오면 같은 번호를 씁니다」가 **이름에서만** 깨져 있었습니다.
화면 복원은 둘 다 「김민수」로 맞게 되지만, 모델은 `[이름-1]` 과 `[이름-2]` 를 두 사람으로 읽을 수 있습니다.

원문을 아는 쪽은 브라우저뿐이므로 고칠 자리도 브라우저뿐입니다. 서버에 원문 장부를 두는 것은
불변 규칙 3 위반이고, 브라우저가 이름을 **찾는** 것(정규식)은 오탐이 폭발합니다
([research/09 §3.1](../docs/research/09-로컬모델-PII인식-실측.md)).

## 결정

1. **브라우저 1차(`pii-masker` 의 `maskText`)는 문맥(`MaskContext`)에 있는 이름 원문이 발화에 나오면
   그 이름표로 바꿉니다.** 이름을 **찾지는 않습니다** — 정규식은 여전히 네 종류뿐이고, 새 이름표를
   발급하지도 않습니다(`added` 에 이름이 들어가지 않으므로 봉해 맡길 것도 없습니다). 긴 이름이 짧은
   이름을 품으면 긴 쪽이 이깁니다. 원문이 없는 예약 칸은 쓰지 않습니다.
2. **재진입 때 `openVault` 는 열어 낸 이름 짝을 발화 문맥에도 넣습니다.** 못 연 이름표는 넣지
   않습니다 — 브라우저는 이름 번호를 발급하지 않으므로 계좌처럼 자리를 예약할 이유가 없습니다.
   같은 세션 안에서는 `absorb` 가 이미 문맥에 합칩니다(ADR-062 ③).
3. **서버 2차(`pii-tokenizer`)는 우리 이름표 모양과 겹치는 모델 조각을 버립니다.** 브라우저가
   `[이름-1]` 을 보내면 그 글자가 입력에 그대로 오는데, 모델이 그것을 사람 이름으로 집으면
   `[이름-2]` 로 다시 가려져 한 사람에 이름표가 둘이 됩니다. 브라우저가 만든 `[계좌-1]` 이
   입력에 오는 것과 같은 상황이라 같은 규칙으로 둡니다.

### 무엇이 안 바뀌나

- **모르는 이름은 여전히 2차의 몫입니다.** 첫 언급은 원문으로 서버까지 가고, 서버가 가리고,
  그 응답의 짝으로 브라우저가 알게 됩니다(ADR-075). 이 결정은 그 다음 언급부터입니다.
- **마스킹 검산(`send.ts` 의 ①'')은 네 종류만 봅니다.** 모르는 이름은 매핑이 없어 검산할 수 없고,
  아는 이름은 바꿔치기가 결정적이라 검산할 것이 없습니다.
- **키 위치·볼트·장부는 그대로입니다.** 서버는 여전히 원문을 모릅니다.

### 따라오는 것 — 슬롯 답에도 같은 길

슬롯 답(§3.5)도 `screenAndSeal` 을 지나므로, **이미 아는 이름이 든 답은 되묻기 없이** 이름표로
저장되고 이 기기에서 복원됩니다. [ADR-067](067-pii-confirm-server-masks.md) 의 「복원되지 않는 칸」은
**모르는 이름**에서만 남습니다. ADR-067 의 표 「브라우저가 가릴 수 있나 — 아니오」는 「모르는 이름은
아니오, 아는 이름은 예」로 읽습니다.

## 탈락한 대안

| 대안 | 왜 탈락 |
| --- | --- |
| 서버가 원문 장부를 갖고 `knownSpans` 로 재사용 | 불변 규칙 3 위반 — 서버가 통째로 유출되면 이름이 읽힙니다 |
| 브라우저가 이름 정규식으로 찾기 | 오탐 폭발(research/09 §3.1). 「토스로 보냈어요」의 기관명까지 가려 유형 분기가 무너집니다 |
| 서버가 같은 응답에 「이 이름표는 이 원문」을 다시 실어 주기 | 서버가 원문을 모르니 실을 것이 없습니다 |
| 그대로 두기 | 모델이 한 사람을 둘로 읽고, ADR-011 「같은 값 → 같은 번호」가 이름에서 거짓입니다 |
