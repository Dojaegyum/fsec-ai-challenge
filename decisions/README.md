# 의사결정 기록 (ADR)

되돌리기 어렵거나 나중에 "왜 이렇게 했더라"가 나올 결정을 한 건에 한 파일로 남깁니다.
주제 확정, 기술 스택, MVP 범위 컷 같은 것들이 대상입니다.

논의가 필요한 **제안**은 [rfc/](../rfc/)에 먼저 쓰고, 채택되면 여기에 결정으로 남깁니다.
결정이 spec을 바꾼다면 [spec/](../spec/) 갱신까지가 한 작업입니다.

## 파일명

`NNNN-결정을-한-문장으로.md` — 예: `0001-출전-주제-선정.md`

번호는 순번이며 재사용하지 않습니다.

## 템플릿

```markdown
# NNNN. <결정 한 문장>

- 상태: 제안 | 채택 | 폐기 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD
- 관련 문서: <../spec/..., ../rfc/..., ../docs/... 등>

## 맥락

무엇을 정해야 했고, 그때 무엇을 알고 있었는지. 제약(시간·인원·데이터 접근)도 여기.

## 결정

무엇으로 정했는지.

## 근거

왜 그것인지. 탈락한 대안과 탈락 사유를 함께.

## 결과

이 결정으로 무엇이 쉬워지고 무엇이 어려워지는지. 나중에 재검토할 트리거가 있으면 명시.
```
