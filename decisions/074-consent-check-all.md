# ADR-074. 동의 조항 다섯을 「전부 확인」 한 번으로 채울 수 있게 한다 — 조항별 확인은 남기고, 동의 단추는 따로 둔다

- 상태: **채택**
- 날짜: 2026-09-06
- 결정: @kth9245 (사용자 결정 — 접수 전 배포본 점검에서 *"다섯 번 클릭은 정당하지만 마찰 … 「전부 확인」 한 번으로도 갈 수 있게 합니다"*)
- 관련 문서: [ADR-031](031-consent-clause-ack.md) (조항별 확인이 동의의 성립 요건 — **일부 대체**: 한 번에 채우는 길을 두지 않은 것과 「재검토 트리거 — 체크 개수를 줄이지 않는다」만. 다섯을 모두 확인해야 동의가 성립하는 것·관문 판정 기준은 **유지**) ·
  [화면 설계 S-05](../spec/frontend/08-14-screens.md) 「동의 — 전문은 모달, 요약은 그 앞에」 (이 결정으로 개정) ·
  [컴포넌트 규칙](../spec/frontend/design-system/08-16-components.md) 「지켜야 할 제약」 (같이 개정) ·
  [접근성](../spec/frontend/design-system/08-16-accessibility.md) 「키보드」 ·
  `src/app/start/page.tsx` 의 `ConsentModal`

## 맥락

접수 마감(2026-09-07 10:00) 전날 배포본을 심사위원의 눈으로 다시 지나가 봤습니다.
`/start` 의 동의 모달에서 두 가지가 걸렸습니다.

- **다섯 번 확인.** 조항 다섯에 각각 「확인했습니다」를 눌러야 [동의하고 계속하기]가
  열립니다 ([ADR-031](031-consent-clause-ack.md)). 요약 카드 넷(180일 파기 · 주민등록번호
  미수집 · 가려진 뒤에야 AI · 학습 미사용)은 차별점으로 잘 읽히는데, 그 아래 다섯 번의 클릭은
  **정당하지만 마찰**입니다. 랜딩이 「진술 한 줄이면 됩니다 · 회원가입 없음」으로 기대를
  낮춰 놓은 뒤라 낙차가 큽니다 — ADR-031 도 이것을 「실제 비용」이라고 적어 두었습니다.
- **「버전 초안 (법무 검토 전)」.** 머리말이 그렇게 적혀 있습니다. 정직한 표기이지만
  심사위원에게는 **미완성**으로 읽힙니다. 이 표기는 ADR 이 아니라 문구라 이 문서의 결정
  대상은 아니고, 「시행 2026-09 · 초안」으로 줄였습니다 — 법무 검토 전이라는 사실은
  `page.tsx` 머리 주석과 ADR-031 에 그대로 남습니다.

ADR-031 은 이탈이 문제로 드러나면 **「체크 개수를 줄이지 않고 조항 수를 줄인다」**고
재검토 방향을 미리 정해 두었습니다. 그 길을 먼저 봤습니다.

- 조항 다섯은 각각 다른 결정이 근거입니다 — 파기([ADR-016](016-retention-and-datastore.md)),
  주민등록번호([ADR-026](026-raw-upload-retention.md)), 토큰화 자리([ADR-067](067-pii-confirm-server-masks.md)),
  위탁·국외([ADR-043](043-gpu-hosting.md) · `page.tsx` 의 `위탁` 주석), 삭제·종결 요청권. 합치면 조항과 근거의 1:1 이 끊깁니다.
- 전문은 **법무 검토 전 초안**입니다. 접수 전날 조항을 다시 쓰는 것은 검토 전 문서를
  검토 없이 한 번 더 고치는 일입니다.

그래서 조항은 그대로 두고, **다섯을 채우는 조작의 수**를 줄이기로 했습니다.

## 결정

**모달 머리의 `확인 N / 5` 옆에 「전부 확인」 단추를 둡니다.** 누르면 다섯 칸이 모두
확인 상태가 되고 [동의하고 계속하기]가 열립니다. 다 채워지면 단추는 사라집니다 —
채울 것이 없기 때문입니다.

**바뀌지 않는 것 셋.**

1. **다섯을 모두 확인해야 동의가 성립합니다.** `canAgree` 는 여전히 `checkedCount === 5` 입니다.
   전부 확인은 다섯을 채우는 **또 하나의 길**이지, 다섯 없이 지나가는 길이 아닙니다.
2. **조항별 확인란은 그대로 남습니다.** 하나씩 확인할 수 있고, 전부 확인 뒤에 하나를
   되돌리면 다시 잠깁니다. 「읽었다」의 표시가 화면에서 사라지지 않습니다.
3. **[동의하고 계속하기]는 따로 누릅니다.** 「전부 확인하고 동의」 한 단추로 합치지 않습니다 —
   확인(읽었다)과 동의(하겠다)는 다른 행위이고, 합치면 ADR-031 이 탈락시킨
   「체크 없이 바로 동의」와 같아집니다. 최소 조작은 **둘**(전부 확인 → 동의)입니다.

**관문은 여전히 동의 하나입니다.** ADR-031 의 판정 기준(「정보를 받아내면 금지, 고지한 것을
확인받으면 허용」)은 그대로 씁니다.

### ADR-031 에서 무엇이 대체되나

| ADR-031 | 이 결정 |
| --- | --- |
| 「검토한 대안」이 한 번에 채우는 길을 두지 않음(조항별 개별 확인만) | **한 번에 채우는 단추를 둠** — 개별 확인은 남김 |
| 「재검토 트리거 — 체크 개수를 줄이지 않고 조항 수를 줄인다」 | **체크 개수도 조항 수도 그대로 두고, 조작 수를 줄임.** 조항 수를 줄이는 것은 법무 검토 뒤의 일 |
| 다섯을 모두 확인해야 동의 성립 · 관문은 동의 하나 · `REQUIRE_ALL_CHECKS` 없음 | **그대로** |

## 근거

**「읽었다」의 흔적은 어차피 화면에만 있습니다.** ADR-031 이 조항별 확인의 가치로 든 것은
「나중에 다툼이 생겼을 때 무엇을 고지했는지를 화면으로 보이기」인데, 확인 다섯은 서버에
기록되지 않습니다(`src/` 어디에도 동의 상태를 저장하는 코드가 없습니다 — 2026-09-06 확인).
그러니 화면에 남는 것은 **조항 다섯과 확인란 다섯이 그려졌다는 것**이고, 전부 확인 뒤에도
그것은 그대로 그려져 있습니다. 개별 클릭 다섯이 더해 주는 것은 「읽는 데 시간을 썼다」는
정황이지 기록이 아닙니다.

**심사위원은 아무 때나 들어옵니다.** 제출 URL 의 첫 관문이 이 모달입니다. 여기서 다섯 번을
눌러야 다음이 보인다면, 그 뒤의 화면(플랜 · 기한 · 서류 안내)이 심사 시간 안에 안 보일 수
있습니다. 투명성을 차별점으로 삼는 서비스라 요약 카드 넷은 남기고, 그 아래의 조작만 줄입니다.

**낭독기·키보드 사용자에게도 단추 하나가 낫습니다.** 체크 다섯을 탭으로 지나가는 것보다
「전부 확인」 한 번이 짧습니다. ADR-031 이 스크롤 기반 활성화를 배제한 이유(기기마다 조작
가능성이 갈림)는 단추에는 해당하지 않습니다.

### 검토한 대안

| 대안 | 왜 아닌가 |
| --- | --- |
| 조항 수를 줄인다 (ADR-031 의 재검토 방향) | 조항마다 근거 ADR 이 다르고, 전문은 법무 검토 전입니다. 접수 전날 검토 없이 다시 쓰지 않습니다 — **법무 검토 뒤에 다시 봅니다** |
| 체크를 없앤다 | 읽었다는 표시 자체가 사라지고, ADR-031 의 판정 기준까지 흔들립니다. 조항이 안 읽히는 UI 로 돌아가는 것 |
| 「전부 확인하고 동의」 한 단추 | 확인과 동의가 합쳐져 「체크 없이 바로 동의」와 같아집니다. 한 번은 읽었다, 한 번은 하겠다여야 합니다 |
| 스크롤 끝에서 활성화 | ADR-031 이 접근성 이유로 배제한 것 — **그대로 배제** |
| 전부 확인을 발(footer)에 둔다 | 잠긴 [동의하고 계속하기]·[닫기] 와 셋이 되어 좁은 화면에서 줄이 무너집니다. 채울 숫자(`확인 N / 5`) 옆이 뜻이 맞는 자리입니다 |

## 결과

**쉬워지는 것** — 동의까지의 최소 조작이 다섯에서 둘로 줍니다. 랜딩의 약속과 첫 화면의
낙차가 줄어듭니다.

**어려워지는 것** — 「조항을 하나씩 읽었다」는 정황이 약해집니다. 이것은 실제 비용이고
정직하게 적어 둡니다. 다섯 조항과 확인란은 그대로 보이므로 **읽을 수 있는 상태**는 유지되지만,
**읽게 만드는 힘**은 줄어듭니다.

**되돌리기** — `ConsentModal` 의 단추 하나와 `Start` 의 `checkAll` 한 줄입니다. 법무 검토가
조항별 개별 확인을 요구하면 그 둘을 빼고 이 문서를 `대체됨`으로 표시합니다. 스위치로 두지
않는 것은 ADR-031 과 같은 이유입니다 — 끌 수 있으면 조용히 꺼지고, 그때 spec 은 안 바뀝니다.

**재검토 트리거** — 법무 검토 결과. 또는 동의 단계 이탈이 그래도 문제로 남으면, 그때는
ADR-031 의 방향(조항 수)을 다시 꺼냅니다.
