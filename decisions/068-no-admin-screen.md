# ADR-068. 관리자 조회 화면을 만들지 않는다 — 계약 §5 는 폐기하고, 문지기와 기록은 남긴다

## 맥락

[API 계약](../spec/common/08-14-api.md) §5 는 2026-08-16 에 **「응답 하나를 놓고 무엇을 보고 그렇게
답했는지 재현할 수 있어야 한다」** 는 요구로 섰습니다 — `/api/admin/cases/{case_token}/messages/{message_id}`
(그 턴의 프롬프트 전문·판단 근거·KB 항목)와 `/trace`(사건 전체 턴 요약), 그리고 그것을 여는 관리자
계정 하나(`ADMIN_USERNAME`·`ADMIN_PASSWORD_HASH`).

그 뒤로 일어난 것은 이렇습니다.

- **라우트가 하나도 안 생겼습니다.** `src/app/api/admin/` 폴더가 없고, 로그인 경로도 없습니다.
  선 것은 **문지기**뿐입니다 — `/api/admin/*` 을 세션 없이 열면 401(`src/lib/gated-paths.ts` ·
  `src/lib/session-cookie.ts` · `src/proxy.ts`). 그 문지기는 「누가 그 폴더에 라우트를 만들어도
  인증 없이 열리지 않게」 하려고 먼저 세운 것입니다.
- **해시 형식이 정본에 없었습니다** → `ADMIN_PASSWORD_HASH` 를 채울 수 없었고, 설정 현황
  (`lib/config-report.ts`)에 「관리자 계정 — 없음」이 계속 떴습니다.
- **2026-08-27 에 QA 범위에서 뺐습니다** — 사용자 여정에 안 들어가고 심사위원도 안 봅니다
  ([QA 계획](../docs/plans/08-23-qa-readiness.md) Task 7).
- **재현에 필요한 기록은 이미 남고 있습니다.** `message.reasoning_masked`(챗 문맥 §5.2)와 감사
  로그(`audit_log` · 데이터 모델 §10)는 화면 없이도 쌓입니다. 없는 것은 그것을 **열어 보는 화면**뿐입니다.

2026-09-04 에 사용자가 **만들지 않기로** 정했습니다.

## 결정

### ① §5 계약을 폐기합니다 — 문서는 남기고 배너를 답니다

엔드포인트 둘·관리자 계정 하나·감사 이벤트 `admin.message_viewed` 는 **만들지 않습니다.**
§5 본문은 지우지 않고(다른 문서가 「관리자도 원문을 못 본다」 같은 원칙을 여기서 인용합니다)
머리에 폐기 배너를 답니다. 되살릴 때는 이 ADR 을 대체하는 새 ADR 로.

### ② `ADMIN_USERNAME`·`ADMIN_PASSWORD_HASH` 는 더 이상 필요한 값이 아닙니다

설정 현황에서 「관리자 계정」 줄을 지웁니다 — 없는 것이 정상인데 「없음」으로 뜨면 운영자가 찾습니다.
환경변수 이름은 `lib/env.ts` 에 남겨 둡니다(문지기가 읽는 자리 · 아래 ③) — 값을 넣지 않으면 됩니다.

### ③ 문지기는 남깁니다

`/api/admin/*` 은 계속 **401** 입니다. 화면을 안 만든다고 그 경로를 여는 것이 아닙니다 —
`gated-paths.ts` 가 적어 둔 이유(누군가 `app/api/admin/route.ts` 를 만들면 그 한 경로만 인증 없이
열린다)는 그대로 유효하고, 지우면 `proxy.ts`·`request.ts` 를 함께 고쳐야 해서 남기는 쪽이 쌉니다.
`session-cookie.ts` 는 문지기가 부를 뿐이라 **잠든 코드**로 둡니다.

### ④ 기록은 그대로 쌓입니다

`reasoning_masked`·감사 로그 저장은 바꾸지 않습니다. 「왜 이런 응대가 나갔나」를 답할 재료는 남고,
답하는 방법이 화면이 아니라 **DB 조회**가 됩니다 — 운영자가 직접 봅니다.

## 근거

**대회 제출까지 이 화면을 여는 사람이 없습니다.** 심사위원은 피해자 화면을 보고, 팀은 DB 를 직접
봅니다. 로그인·해시 형식·화면 셋을 만드는 비용이 그 뒤에 쓰일 자리보다 큽니다.

**안 만든다고 위험이 늘지 않습니다.** 위험했던 것은 「경로는 있는데 인증이 없는 상태」였고, 문지기가
그것을 막고 있습니다. 화면이 없으면 열릴 것도 없습니다.

**되돌리기가 쌉니다.** 계약 본문·문지기·잠든 세션 코드가 그대로 있어, 되살릴 때는 라우트 둘과
로그인 경로만 더하면 됩니다.

### 검토한 대안

| 대안 | 왜 아닌가 |
| --- | --- |
| **만든다** (로그인 · 해시 형식 확정 · 화면 둘) | 대회 안에 쓸 사람이 없습니다. 해시 형식은 정본에 없어 그것부터 정해야 합니다 |
| **코드까지 걷어낸다** (`gated-paths`·`session-cookie`·`proxy` 의 관리자 갈래 삭제) | 지우면 `/api/admin/*` 이 열리는 방향입니다. 문지기는 남겨야 하고, 그러면 세션 코드도 따라 남습니다 — 지우는 비용이 남기는 비용보다 큽니다 |
| **§5 를 통째로 지운다** | 「관리자도 원문 개인정보를 볼 수 없다」(§5.3)를 다른 문서가 인용합니다. 지우면 링크가 깨지고 원칙도 사라집니다 — 배너로 폐기 표시 |

## 결과

- [API 계약](../spec/common/08-14-api.md) §5 머리에 폐기 배너 · §1.2 의 `ADMIN_*` 두 행 취소선.
- `src/lib/config-report.ts` 에서 「관리자 계정」 줄 삭제 · `src/.env.example` 의 두 줄에 폐기 표시.
- `src/lib/gated-paths.ts`·`session-cookie.ts` 머리말에 「화면은 만들지 않기로(ADR-068) — 문지기용」.
- [ARCHITECTURE](../ARCHITECTURE.md) 환경변수 표 · [deploy/README](../deploy/README.md) §1 · [챗 문맥](../spec/backend/08-16-chat-context.md) §5.2 · QA 계획 Task 7 · doc-gardening §1 의 관리자 행 셋 — 같은 방향으로.
- **`reasoning_masked` 를 보는 방법이 정본에 없어집니다** — 「DB 를 직접 본다」가 답입니다. 운영이 시작되어
  화면이 필요해지면 이 ADR 을 대체합니다.

## 어떻게 지키나

- `src/lib/gated-paths.test.ts`·`proxy` 시험이 `/api/admin/*` 401 을 그대로 봅니다 — 문지기는 이 결정과 무관하게 섭니다.
- `route-contract` 검사기는 `src/app/api/admin/` 에 라우트가 생기면 다른 라우트와 같은 규칙을 요구합니다 —
  만들려면 이 ADR 을 먼저 대체하세요.
