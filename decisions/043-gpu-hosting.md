# ADR-043. GPU 는 개발에선 빌리고, 운영에선 국내에서만 돈다

- 상태: **채택**
- 날짜: 2026-08-21
- 결정: @Dojaegyum
- 관련 문서: [GPU 클라우드 단가](../docs/research/13-GPU-클라우드-단가.md) ·
  [로컬 모델 PII 실측](../docs/research/09-로컬모델-PII인식-실측.md) §6.2 ·
  [로컬 OCR PII 실측](../docs/research/11-로컬OCR-PII인식-실측.md) §8 ·
  [PII 격리 경계](../spec/common/08-14-pii-boundary.md) (**이 결정이 지키려는 것**) ·
  [ARCHITECTURE](../ARCHITECTURE.md) §6 「STT·OCR 은 경계 이전」 ⚠️

## 맥락

**로컬 모델을 쓰기로 한 것은 선택이 아니라 귀결이었습니다.**

STT·OCR·NER 은 전부 `pii-tokenizer` **이전** 단계입니다. 음성을 토큰화한 뒤 전사할 방법이 없으니,
외부 API 를 쓰면 원문 PII 가 그대로 나갑니다 —
[불변 규칙 2](../CLAUDE.md) 위반입니다.

그런데 [실측](../docs/research/09-로컬모델-PII인식-실측.md)에서 **CPU 로는 서비스가 안 된다**는 것이 드러났습니다.

| 단계 | CPU 실측 |
| --- | ---: |
| 전사 · whisper medium | 음성 길이의 **2.9배** |
| PII 인식 · gemma3:4b | 발화당 **27.7초** |
| OCR · EasyOCR | 장당 **87초** |

한 사건(녹음 7분 + 화면 3장 + 진술 12발화)에 **48분**입니다. 폴링 구조라 동기 응답 제약은
없지만, 진술하고 한 시간을 기다리는 것은 서비스가 아닙니다.

**그래서 GPU 가 필요한데, GPU 를 어디에 두느냐가 PII 경계를 다시 건드립니다.**

## 결정

**개발과 운영을 갈라 정합니다.**

### 개발·대회 데모 — 해외 GPU 를 시간 단위로 빌린다

| | |
| --- | --- |
| 무엇 | RunPod **Pod (Community)** · RTX A5000 24GB 급 |
| 왜 Pod 인가 | 벤치마크는 SSH 로 들어가 스크립트를 돌리면 끝입니다. 서버리스는 컨테이너 이미지를 만들어 올려야 합니다 |
| 얼마 | 시간당 $0.16 → 벤치마크 1회 약 **336원** (설치·모델 내려받기 포함 1.5시간) |
| **절대 조건** | **합성 데이터만 올립니다.** 실제 피해자의 음성·이미지는 올리지 않습니다 |
| **끝나면** | 정지(stop)가 아니라 **삭제(terminate)** 합니다 |

**합성 데이터만 쓰므로 국외 이전에 해당하지 않습니다** — 개인정보가 아니기 때문입니다.
이 조건이 깨지는 순간 아래 운영 규칙이 적용됩니다.

**삭제를 규칙으로 두는 이유**는 [단가 조사 §2.2](../docs/research/13-GPU-클라우드-단가.md)에 있습니다 —
**정지 중 볼륨이 가동 중보다 비쌉니다**($0.20 vs $0.10 /GB·월). 모델 20GB 를 남기면
월 5,600원으로, 벤치마크 1회 비용의 17배입니다.

### 운영 — 원문 PII 가 지나는 추론은 국내에서만 돈다

**`pii-tokenizer` 이전 단계(STT·OCR·NER)를 국외 하드웨어에서 돌리지 않습니다.**

토큰화를 마친 뒤의 호출(플랜 생성·챗)은 이 제약을 받지 않습니다 — 이미 토큰만 나갑니다.

| 단계 | 어디서 | 왜 |
| --- | --- | --- |
| STT · OCR · NER | **국내** | 평문 음성·이미지·텍스트를 다룹니다 |
| 플랜 생성 · 챗 (Grok) | 지금대로 | 토큰화 텍스트만 나갑니다 |

**벤더는 아직 안 정합니다** — 국내 GPU 시간당 단가를 못 구했습니다
([단가 조사 §2.4](../docs/research/13-GPU-클라우드-단가.md) G-02). 후보는 네이버 클라우드 플랫폼·NHN Cloud 이고,
**단가와 스케일 투 제로 지원 여부를 확인한 뒤 이 ADR 을 잇는 새 ADR 로 정합니다.**

### 형태 — 상시가 아니라 요청당

**스케일 투 제로(초당 과금)를 기본으로 합니다.**

`transcriber` 는 **증거가 들어올 때만** 돕니다. 진술만 하고 파일을 안 올리는 사용자에겐 아예 안 돕니다.
띄엄띄엄 오고, 비동기이고, 폴링 구조라 콜드 스타트를 감당할 수 있는 워크로드입니다.

| | 월 비용 |
| --- | ---: |
| 상시 가동 (A5000급) | 약 16만 원 — 대부분 놀립니다 |
| 요청당 과금 | 사건당 수십\~수백 원 |

## 근거

### 왜 운영에서 국외를 막나 — 법이 아니라 약속 때문입니다

**법적으로는 막히지 않습니다.** [개인정보 보호법 제28조의8 제1항 제3호](../docs/research/13-GPU-클라우드-단가.md)가
*"정보주체와의 계약의 체결 및 이행을 위하여 처리위탁·보관이 필요한 경우"* 를 허용하고,
별도 동의 없이 **처리방침 공개**로 갈음할 수 있습니다.

**그런데 우리는 그 이상을 약속했습니다.**

> **이 문서의 규칙은 협상 대상이 아닙니다** — 서비스의 신뢰 근거이자 심사 차별점입니다.
> — [PII 격리 경계](../spec/common/08-14-pii-boundary.md)

세 가지가 걸립니다.

**1. 동의를 받는 방식이 이 서비스와 안 맞습니다.** 처리방침 공개로 갈음할 수 있다지만,
그 말은 **사용자가 모르는 채로 국외로 나간다**는 뜻이기도 합니다. 우리는 반대로
*"서버가 통째로 유출돼도 원문을 읽을 수 없다"* 를 내세우고 있습니다.
[ADR-021](021-reentry-and-identity.md)이 진입을 검색·직접 접속으로 전제해 동의 화면이 이미 부담인데,
여기에 국외 이전 고지를 얹으면 **패닉 상태의 피해자에게 읽으라고 하는 글이 한 장 더 늘어납니다.**

**2. 심사에서 물어볼 자리입니다.** 금융보안원이 주관하는 대회이고, 우리가 내세운 차별점이
PII 경계입니다. *"음성은 어디서 처리하나요"* 에 *"미국 GPU 입니다"* 라고 답하는 순간
차별점이 흔들립니다.

**3. 되돌리기 어렵습니다.** 운영에 올라간 뒤 국내로 옮기려면 인프라를 갈아야 합니다.
지금 제약을 걸어두는 비용은 **후보가 줄어드는 것**뿐입니다.

### 왜 개발은 해외를 허용하나

**합성 데이터에는 지킬 개인정보가 없습니다.** 평가셋의 계좌·주민번호·이름은 전부 임의값이고
([09 §2.1](../docs/research/09-로컬모델-PII인식-실측.md)), 실존 인물과 무관합니다.

그리고 **국내 단가를 모르는 채로 개발까지 국내로 묶으면 실측 자체가 막힙니다.**
알아야 할 숫자를 못 구하게 되는 셈이라 순서가 뒤집힙니다.

### 왜 벤더를 지금 안 정하나

**단가를 모릅니다.** 공개 페이지에서 못 찾았고, 추측으로 ADR 을 쓰면
[작업 규칙](../CLAUDE.md)의 *"모르는 절차·수치를 지어내지 마세요"* 를 어깁니다.

**다만 「국내에서만」 이라는 제약은 단가와 무관하게 지금 정할 수 있습니다** —
이게 벤더 선정보다 앞선 결정이고, 후보 목록을 가르는 기준이기 때문입니다.

### 검토한 대안

| 대안 | 왜 아닌가 |
| --- | --- |
| 운영도 해외 서버리스 | 가장 싸고 스케일 투 제로도 성숙합니다. **그런데 위 세 가지** |
| 운영에 자체 GPU 서버 구입 | 초기 비용이 크고, 대회 단계에서 회수 근거가 없습니다. 트래픽이 확인되면 다시 볼 수 있습니다 |
| 국외 이전 동의를 받고 해외 사용 | 법적으로 가능하지만 **패닉 사용자에게 동의 화면을 하나 더** 얹습니다 |
| 지금 벤더까지 확정 | 국내 단가를 모릅니다. 지어내면 규칙 위반 |
| GPU 없이 CPU 로 운영 | 한 사건 48분. 서비스가 아닙니다 |

## 결과

**RunPod·Modal·Vast.ai 는 운영 후보에서 빠집니다.** 개발용으로만 씁니다.

**개발 규칙 둘이 코드 바깥의 약속으로 남습니다** — 합성 데이터만 올리기, 끝나면 삭제하기.
**검사기가 잡을 수 없는 규칙**이라 사람이 지켜야 합니다.

**`ARCHITECTURE.md` §6 의 「STT·OCR 은 경계 이전 ⚠️」 경고가 이 결정으로 구체화됩니다** —
경고에 머물던 것이 배치 제약이 됩니다.

**미결이 둘 남습니다.**

- **운영 벤더** — 국내 단가 확인 후 새 ADR. 후보는 네이버 클라우드 플랫폼·NHN Cloud
- **스케일 투 제로 지원 여부** — 국내 공급자가 초당 과금을 안 하면 비용 구조가 달라집니다.
  그때는 「요청당」이라는 이 결정의 형태 부분을 다시 봐야 합니다

**재검토 트리거** — ① 국내 단가를 구했을 때 ② 실제 트래픽이 상시 가동을 정당화할 때
③ [PII 격리 경계](../spec/common/08-14-pii-boundary.md)가 개정될 때.
셋 중 하나라도 오면 이 ADR 을 잇는 새 ADR 을 씁니다.
