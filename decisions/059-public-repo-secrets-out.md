# ADR-059. 저장소를 공개로 — 비밀은 Vercel env 에만 두고, 이력에 남은 값은 새 저장소로 지운다

- 결정: @Dojaegyum

## 맥락

2026-08-26 에 배포가 막힌 원인 하나가 **Vercel 팀이 Hobby** 라는 것이었다
(`deploy/README.md` 「막히는 두 가지」①). Hobby 팀은 비공개 저장소에서 소유자가 아닌
작성자의 커밋을 받지 않는다 — Vercel 문서가 *"the commit author must be the owner of
the Hobby team"* 이라고 못 박고, *"Collaboration is free for public repositories"* 라고
덧붙인다. 워크플로가 `.git` 없는 사본을 올려 우회하고 있지만, 우회는 우회다.

공개로 바꾸면 얻는 것이 셋이다.

| 얻는 것 | 지금 |
| --- | --- |
| Vercel 작성자 제한이 사라진다 | 사본 배포로 우회 중 |
| GitHub Actions 분이 무제한이다 | 비공개 Free 는 월 2,000분 — 워크플로 여덟이 푸시마다 돈다 |
| 브랜치 보호를 켤 수 있다 | ADR-053 은 「비공개 Free 라 못 켠다」는 전제 위에 서서 게이트를 배포 잡 안에 뒀다 |

대회 규정에 비공개 조건은 없다 — 소스는 압축파일로 별도 제출한다(`docs/context/AGENDA.md`).

막는 것이 하나다. **`src/.env.local` 이 실값째 git 에 추적되고 있다** — 2026-08-24 부터
35 커밋. 두 사람이 설정을 나누는 통로로 일부러 넣은 것이었고, 비공개라서 괜찮았다.
파일 머리말은 「커밋되지 않습니다」라고 적혀 있었고 `.gitignore` 에도 `.env*` 가 있었다 —
이미 추적된 파일에는 ignore 가 안 걸린다. 공개되는 순간 지금 트리뿐 아니라 **이력
전체**가 열린다.

380 커밋의 모든 패치를 훑어 확인한 것: 비밀이 든 파일은 **이것 하나**다. 다른 히트는
전부 예시값(`postgres.xxxx:PASSWORD@…`, 시험의 `user:pass@host`, README 의 `<bootstrap 이
찍어 준 값>`). 든 값은 여덟 가지, 아홉 개 버전이다.

| 값 | 무엇을 여나 |
| --- | --- |
| `DATABASE_URL` · `DIRECT_URL` | DB 비밀번호 — 사건·볼트 표 전부 |
| `SUPABASE_SERVICE_ROLE_KEY` | 행 단위 접근 제어를 통과하는 키 |
| `LLM_API_KEY` (Gemini) · `XAI_API_KEY` | 언어모델 과금 |
| `RUNPOD_API_KEY` | GPU Pod 를 띄우는 권한 — 과금 |
| `TRANSCRIBER_TOKEN` (버전 2) · `CRON_SECRET` | 전사 서버와 크론 엔드포인트의 문 |

프로덕션은 이미 이 파일을 쓰지 않는다. Vercel Production env 에 16개가 들어 있고,
CLI 는 업로드 때 `.env.local` 을 버린다(배포 파일 목록으로 확인). 이 파일이 하던 일은
**로컬 개발값 공유**와 **주석 139줄짜리 실측 메모**뿐이다.

## 결정

순서가 곧 결정이다 — **B → C → A.** 공개는 마지막이다.

### A. 저장소를 공개로 바꾼다

`Dojaegyum/fsec-ai-challenge` 를 public 으로. 그 뒤에 할 수 있게 되는 것(브랜치 보호,
Vercel 사본 배포 걷어내기)은 여기서 정하지 않는다 — 각각 따로 본다.

### B. `.env.local` 은 git 에서 뺀다 — 비밀의 정본은 Vercel env

- `git rm --cached src/.env.local`. 이제부터 `.gitignore` 의 `.env*` 가 작동한다.
- 주석에 있던 메모(모델 실측 · Ollama · 한 턴 비용 · 전사 서버 위치)는 값을 비운 채
  `.env.example` 로 옮긴다. **`.env.example` 이 무엇이 왜 필요한지의 정본이다.**
- 로컬 값은 소유자가 직접 건넨다. Hobby 팀이라 팀원은 `vercel env pull` 을 못 쓴다.
  `VERCEL_TOKEN` 은 계정 토큰이라 건네지 않는다.
- 추적 해제가 머지되면 **팀원의 다음 `git pull` 이 로컬 `.env.local` 을 지운다**(변경
  없이 추적 파일이 삭제되면 그렇게 된다). pull 전에 복사본을 두고, 새 값은 따로 받는다.

### C. 이력에서 지운다 — 걸러 낸 이력을 같은 이름의 새 저장소에 올린다

값은 재발급하지 않는다. 대신 **그 값이 든 커밋을 공개하지 않는다.**

1. 미러 클론에서 `git filter-repo --invert-paths --path src/.env.local` — 전 브랜치에서
   그 파일만 빠진 이력이 나온다(428 → 422 커밋. 그 파일만 만진 여섯은 빈 커밋이 되어
   사라진다). 걸러 낸 이력을 다시 훑어 비밀이 0건임을 확인한다.
2. 지금 저장소는 **`fsec-ai-challenge-private` 로 이름을 바꿔 비공개로 남긴다** — PR·이슈
   페이지의 이력이 거기 있다.
3. 새 `fsec-ai-challenge` 를 만들어 걸러 낸 브랜치 전부를 올린다. 이름을 물려받으니 URL 과
   로컬 클론의 원격 주소가 그대로다. Actions 시크릿 셋(`VERCEL_*`)과 협업자를 다시 넣는다.
4. 올라간 것을 확인한 뒤 공개로 바꾼다 — **공개는 마지막이다.**

**제자리에서 강제 푸시하지 않는다.** GitHub 는 강제 푸시 뒤에도 PR 의 옛 커밋을
`refs/pull/N/head` 로 붙들어 둔다(이 저장소에 86개). 지원 요청으로 지우기 전까지 그
경로로 닿으므로, 그 사이에 공개하면 빈틈이다. 새 저장소에는 그 ref 가 애초에 없다.

**이력이 바뀌면 클론이 갈린다.** 협업자는 재클론하고, 로컬 브랜치는 원격 것으로 다시
맞춘다. 로컬 `.env.local` 은 옛 이력에서 추적 파일이었으므로 재동기화 때 지워진다 —
먼저 복사해 둔다.

## 근거

**값이 밖으로 나간 적이 없다.** 그 커밋들은 비공개 저장소 안에서 두 사람만 봤다. 나간
적이 없는 값은 죽일 이유가 없고, **나가지 않게만 하면 된다** — 그 커밋을 공개하지 않는 것.

**재발급은 손이 많이 간다.** 여덟 값이 대시보드 일곱 곳에 흩어져 있고, `LLM_API_KEY` 는
다른 프로젝트(FinAI)와 나눠 쓰던 키라 그쪽까지 바꿔야 한다. 걸러 낸 이력을 올리는 것은
한 사람이 한 번에 끝낸다.

**같은 이름의 새 저장소여야 빈틈이 없다.** 위 C — 제자리 강제 푸시는 PR ref 가 남는다.

**공개는 마지막이다.** 봇이 공개 저장소를 훑는 데 몇 분이면 된다. 걸러 낸 것만 올라간
것을 확인한 뒤에 연다.

### 검토한 대안

| 대안 | 왜 아닌가 |
| --- | --- |
| **Pro 플랜으로 올려 팀원을 추가** (비공개 유지) | 월 $20/석. 비공개를 유지할 이유가 대회 규정에 없고, Actions 분·브랜치 보호는 여전히 막혀 있다 |
| **값을 전부 재발급하고 이력은 그대로 공개** | 빈틈은 없다. 하지만 대시보드 일곱 곳을 돌고 FinAI 와 나눠 쓰는 키까지 바꿔야 한다 — 나간 적 없는 값을 죽이는 비용이다 |
| **제자리에서 이력 재작성 + 강제 푸시** | PR 페이지·URL 이 그대로 남아 좋지만, `refs/pull/N/head` 가 옛 커밋을 붙들어 GitHub 지원이 지워 줄 때까지(며칠) 공개를 못 한다 |
| **이력은 두고 재발급도 안 하기** | 불가. 공개 즉시 값이 살아 있는 채로 열린다 |

## 결과

**쉬워지는 것** — kth9245 님이 머지해도 배포가 막히지 않는다. Actions 분을 세지 않아도
된다. 브랜치 보호를 켤 수 있다(따로 정한다). 로컬 값이 git 을 타지 않으니 「누가 무슨
값을 올렸나」를 걱정할 자리가 없어진다.

**어려워지는 것** — 로컬 값을 나누는 통로가 사람 손이다. 값이 바뀌면 소유자가 건네야
한다. Pro 로 가면 `vercel env pull` 이 그 통로가 된다 — 그때 B 의 「직접 건넨다」를
다시 본다. PR 페이지가 두 저장소에 갈린다 — #85 까지는 비공개 저장소
(`fsec-ai-challenge-private`)에, 그 뒤는 새 저장소에. 문서와 커밋 메시지가 적은 `#NN` 은
앞엣것이다.

**재검토 트리거** — 대회 규정이 비공개를 요구하면 A 를 되돌린다(B·C 는 그대로 옳다).
브랜치 보호를 켜면 ADR-053 의 「게이트를 배포 잡 안에 둔다」를 다시 본다.
