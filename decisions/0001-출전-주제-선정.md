# 0001. 출전 주제를 01번 보이스피싱 골든타임(골든30)으로 한다

- 상태: **채택**
- 날짜: 2026-08-13 (기획서 v1.2 작성 시점 기준 — TODO: 실제 확정 시점 확인)
- 관련 문서: [기획서](../docs/plans/골든30-서비스기획서.html) · [정합성 분석](../docs/context/주최기관-정합성-분석.html) · [후보군 보드](../docs/candidates/주제후보군-보드.html)

> 기록용 ADR입니다. 결정 자체는 기획서 v1.2에 "채택된 01번"으로 이미 반영돼 있고,
> 이 문서는 그 근거를 후보 문서들에서 모아 남긴 것입니다.

## 맥락

후보 9건 + 팀 아이디어를 보드로 정리해 Tier 1 4건(01 보이스피싱 / 02 금융약관 해석기 / 03 소상공인 금융매칭 / 13 보안관제 비서)까지 좁혔고, 각각 컨셉 스펙까지 작성한 상태였습니다.

제약:

- 2026년 대회는 아이디어 공모가 아니라 **실작동 서비스 구현·검증**이 요구됩니다.
- 팀은 개발자 중심이라 금융 도메인 지식이 얕고, 실거래 데이터에 접근할 수 없습니다.
- 심사 기준은 AI 개발역량 · 문제해결력 · 구현 가능성.

## 결정

**01번 보이스피싱 골든타임 네비게이터(골든30)** 로 출전합니다. 데스크톱 웹 데모 기준.

## 근거

정합성 분석의 결론은 금융보안원 심사에서 강한 조합이 **「보안·안전 DNA × 대고객 체감 서비스」의 교집합**이라는 것이었고, 01번이 1순위 후보군으로 판정됐습니다.

- **FSI 본업 정합** — 이상금융거래정보 공유는 금융보안원 실사업이고, 보안 기관이 주최하는 대회에서 '소비자 보호 보안 서비스'는 양쪽 코드를 모두 충족합니다.
- **대고객 체감 최상급** — 전작(2025) 대상·우수상이 모두 "특정 대상의 구체적 어려움을 푸는 서비스"였고, 원장이 성료 소감에서 강조한 것도 대고객 서비스 활용 가능성이었습니다.
- **실작동 데모 용이** — 공개 자료 중심이라 실거래 데이터가 필요 없고, 규제 부담이 낮습니다.
- **차별화 각도** — 대회 예시 주제이지만 기존 서비스가 몰린 '탐지'가 아니라 **사후 골든타임 대응**으로 각도를 틀었습니다. 특히 경유 서비스 8유형별 절차 분기는 기존에 없던 지점입니다.

### 탈락 후보와 사유

| 후보 | 사유 (정합성 분석 기준) |
| --- | --- |
| 02 금융약관 해석기 | 대고객 체감은 상급이나 FSI 보안 사업축과 거리가 있음 |
| 03 소상공인 금융매칭 | FSI 사업축과 무관 + **전작 대상작 SIGNAL과 동일 계층** — 차별화 부담이 가장 큼 |
| 13 보안관제 AI비서 | 2026 어젠다 정합은 최상이나 B2B라 대고객 체감 코드와 거리. 데모 임팩트 확보가 어려움 |

## 결과

**쉬워지는 것**

- 데이터 확보 부담이 낮습니다 (공개 자료 중심).
- 데모 스토리가 강합니다 — 피해 직후 상황을 5분 안에 보여줄 수 있습니다.

**어려워지는 것 · 감수한 비용**

- **경유 서비스 8유형 매뉴얼 KB 구축**이 필수 작업으로 들어옵니다. 절차 지식은 창작이 불가능해 전부 근거를 확인해야 합니다 → [spec/30](../spec/30-channel-matrix.md), [spec/70](../spec/70-kb-operations.md)
- **PII 격리 설계**가 선택이 아닌 전제가 됩니다. 피해자의 계좌·주민번호를 다루기 때문입니다 → [spec/40](../spec/40-pii-boundary.md)
- 제도 변경에 노출됩니다 (가상자산 환급 2026.10 시행 등) — 버전드 KB로 흡수하는 구조를 택했습니다.
- 데스크톱 우선이라 **모바일 대응이 P1로 밀립니다.** 실제 피해 상황은 폰만 있는 경우가 많다는 점이 이 결정의 약점이고, 재검토 트리거입니다.

## 재검토 트리거

- 심사에서 모바일 미지원이 감점 요인으로 드러나면 모바일 반응형을 P0로 올립니다.
- 13번(보안관제)의 프론티어 AI 위협 대응 각도는 버리지 않고, **판별 엔진에 프롬프트 인젝션 탐지를 한 기능 넣는 하이브리드**로 흡수했습니다 (정합성 분석 §6-③).
