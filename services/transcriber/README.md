# transcriber 서비스 — 모델을 돌리는 자리

앱(`src/`)은 **모델을 안 올립니다.** Vercel 서버리스 함수에 모델을 띄울 수 없기 때문입니다
→ [ADR-028](../../decisions/028-runtime-and-module-shape.md). 그래서 읽는 일만 여기로 뺐습니다.

| | |
| --- | --- |
| 무엇을 하나 | 녹음을 글로 · 이미지에서 글자를 |
| 무엇을 **안 하나** | 토큰화 · 화자 이름표 · 말풍선 좌우 판정 · 저장 |
| 짝 | `src/modules/transcriber/` (판단은 전부 그쪽) |
| 배치 | 개발은 빌린 GPU · **운영은 국내** ([ADR-043](../../decisions/043-gpu-hosting.md)) |

## 왜 판단을 앱에 두나

**제품을 바꾸면 바뀌는 것만 여기 둡니다.** 모델을 갈아끼우면 이 서비스는 바뀌지만
앱은 안 바뀝니다. 반대로 「먼저 말한 쪽이 A」나 「말풍선 좌우로 화자를 가른다」는
엔진과 무관한 판단이라 앱에 있습니다.

**토큰화는 특히 여기서 하지 않습니다.** 경계는 `pii-tokenizer` 하나이고,
여기가 두 번째 경계가 되면 우회할 자리가 둘이 됩니다
→ [PII 격리 경계](../../spec/common/08-14-pii-boundary.md).

## 띄우기

```bash
cd services/transcriber
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt

cd ..
./transcriber/.venv/bin/python -m uvicorn transcriber.app:app --port 8917
```

**모델 없이 바로 돕니다.** 기본이 `echo` 라 흐름 전체(업로드 → 접수 → 폴링 → 정규화 →
확인 화면)를 모델을 안 내려받고 시험할 수 있습니다. 결과에 `engine: "echo"` 가 붙어
**진짜로 읽은 것이 아님이 드러납니다.**

### 모델을 실제로 붙일 때

```bash
./.venv/bin/pip install -r requirements-models.txt
FINALLY_ENGINE=local ./.venv/bin/python -m uvicorn transcriber.app:app --port 8917
```

## 서버에 올리기

개발용으로 손으로 띄우는 것은 위 「띄우기」입니다. 여기는 **앱이 실제로 부를 수 있게
서버에 올리는 절차**입니다.

### 준비물

| | 필요값 | 왜 |
| --- | --- | --- |
| 메모리 | **4GB 이상** | 모델 둘이 2,259MB 를 붙듭니다(실측). 2GB 서버에는 안 올라갑니다 |
| 디스크 | 20GB 이상 | 모델 파일 약 1.5GB + 이미지 1.8GB |
| CPU | 많을수록 빠름 | 6코어에서 실시간의 1.09배(실측). 2코어면 4~5배로 잡으세요 |
| 도메인 | 하나 | **암호화가 선택이 아닙니다** — 아래 |

x86 과 ARM 둘 다 됩니다. `Dockerfile` 이 아키텍처를 보고 알아서 갈라집니다.

### ⚠️ 이 구간에는 원문이 흐릅니다

서비스가 앱에 돌려주는 것은 **전사 결과 전문**입니다. 아직 토큰으로 안 바뀐,
계좌번호와 이름이 그대로 있는 글입니다 → [PII 격리 경계](../../spec/common/08-14-pii-boundary.md).

그래서 둘이 **필수**입니다. 하나라도 빠지면 이 프로젝트가 지키기로 한 경계가
첫 구간에서 무너집니다.

1. **HTTPS.** `compose.yaml` 이 앞에 Caddy 를 세워 인증서를 저절로 받아 옵니다.
2. **공유 비밀값(`FINALLY_TOKEN`).** 비면 아무나 부를 수 있고, 이 서비스는 **넘겨받은
   주소를 그대로 내려받으므로** 열어 두면 남의 심부름을 하게 됩니다.

### 절차

```bash
# 1. 서버에 파일을 올립니다
scp -r services/transcriber ubuntu@<서버주소>:~/

# 2. 서버에서 한 번 돌립니다 — 도커·방화벽·스왑·비밀값까지 잡습니다
ssh ubuntu@<서버주소>
cd transcriber && bash bootstrap.sh
```

처음 돌리면 `.env` 를 만들고 **비밀값을 찍어 줍니다.** 그 값을 앱 쪽
`TRANSCRIBER_TOKEN` 에 넣으세요. 그리고 `.env` 의 `TRANSCRIBER_DOMAIN` 을 채운 뒤
`bootstrap.sh` 를 다시 돌리면 뜹니다.

```bash
# 3. 앱 쪽 환경변수 (Vercel 프로젝트 설정)
TRANSCRIBER_URL=https://<도메인>
TRANSCRIBER_TOKEN=<bootstrap 이 찍어 준 값>
```

### 도메인이 없을 때

셋 중 하나로 채웁니다.

| 방법 | 값의 모양 | 비용 |
| --- | --- | --- |
| 가진 도메인 | `transcriber.example.com` | 이미 있음 |
| **sslip.io** | `1-2-3-4.sslip.io` (공인 IP 의 점을 `-` 로) | **0원** |
| Cloudflare Tunnel | 포트를 안 열어도 됩니다 | 0원 |

sslip.io 는 IP 를 그대로 도메인으로 바꿔 주는 공개 서비스라 인증서도 정상으로
받아집니다. **서버 IP 가 바뀌면 같이 바꿔야 합니다** — 고정 IP 로 잡아 두세요.

### 오라클 클라우드라면 — 막는 곳이 두 군데입니다

`bootstrap.sh` 가 서버 안쪽 방화벽은 엽니다. 그런데 **웹 콘솔에도 따로 있습니다.**
한쪽만 열고 "왜 안 닿지" 하는 일이 흔합니다.

> 네트워킹 → 가상 클라우드 네트워크 → 서브넷 → 보안 목록 → 수신 규칙
> `0.0.0.0/0` 의 TCP **80·443** 을 추가

무료 등급의 ARM 서버(2코어·12GB)는 인기가 많아 **「용량 부족」으로 생성이 거절되는
일이 흔합니다.** 며칠 재시도해야 할 수 있습니다.

### 확인

```bash
curl https://<도메인>/health
```

`"ready": true` 면 모델까지 올라간 것입니다. 처음 뜰 때는 모델 1.5GB 를 받느라
몇 분 걸립니다 — `docker compose logs -f transcriber` 로 「모델 적재 완료」를 기다리세요.

### 얼마나 걸리나 — 실측

**오라클 애슈번 A1.Flex · 2코어 · `medium`/`int8`/beam 5 에서 음성 길이의 3.7배**
(2026-08-24, 61초 음성 → 225초). 두 코어를 179% 로 다 씁니다 — 놀아서 느린 게
아니라 그 기계가 낼 수 있는 값입니다.

| 녹음 길이 | 걸리는 시간 |
| --- | --- |
| 1분 | 약 4분 |
| 5분 | 약 19분 |
| 10분 | 약 37분 |

> 같은 기계에서 CUDA 판 torch 를 얹었을 때는 4.6배였습니다. GPU 를 한 번도 안 쓰는데
> 4.6 → 3.7 로 줄었습니다 — 무거운 의존성은 디스크만 먹는 게 아닙니다.

**이 숫자가 화면의 약속을 정합니다.** 접수·폴링 구조인 것이 이래서 맞습니다 —
사람을 기다리게 두면 안 되고, 「다 되면 알려 드립니다」로 가야 합니다.

빠르게 만드는 길은 셋이고, **모델을 줄이는 것은 그중에 없습니다** — 실측
([docs/research/09](../../docs/research/09-로컬모델-PII인식-실측.md) R-5)이
*"base 는 리터럴 생존 5~10%"* 라고 못 박았습니다. 계좌번호가 안 살아남으면
뒤의 개인정보 처리가 통째로 무의미해집니다.

| 무엇 | 얼마나 | 대가 |
| --- | --- | --- |
| `FINALLY_VAD=1` | 무음만큼 | 통화 녹음은 무음이 많아 실제로 꽤 줄어듭니다. **먼저 해볼 것** |
| `beam_size` 를 1 로 | 2~3배 | 정확도가 떨어집니다. **재보고 정하세요** — 리터럴 생존을 다시 재야 합니다 |
| 코어를 늘린다 | 대략 비례 | **돈이 듭니다** — 아래 |

⬜ 위 셋 중 무엇도 아직 안 했습니다. 지금 값이 3.7배입니다.

> ⚠️ **코어를 더 못 늘립니다 — 지금이 무료 한도 전부입니다.**
>
> 오라클 Always Free 의 Ampere A1 몫은 **월 1,500 OCPU 시간 · 9,000 GB 시간**이고,
> 24시간 내내 돌리면 **2코어 · 12GB** 입니다
> ([Always Free Resources](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)).
> 이 서버가 정확히 그 값이라 **한 코어만 더해도 과금이 시작됩니다.**
>
> 이 문서는 2026-08-24 에 「무료 한도가 4 OCPU 라 절반만 쓴다」고 잘못 적었습니다.
> 예전 한도였고 지금은 아닙니다. 늘리려면 요금을 각오해야 합니다.

## 설정

| 환경변수 | 기본 | 무엇 |
| --- | --- | --- |
| `FINALLY_ENGINE` | `echo` | `echo` \| `local` |
| `FINALLY_WARMUP` | (없음) | `1` 이면 뜰 때 모델을 미리 올립니다. 첫 사용자가 20초를 안 맞게 |
| `FINALLY_DEVICE` | `cpu` | `cpu` \| `cuda` |
| `FINALLY_STT` | `medium` | 전사 모델 크기 |
| `FINALLY_COMPUTE` | `int8` | `int8`(CPU) \| `float16`(GPU) |
| `FINALLY_VAD` | `0` | 무음 건너뛰기 |
| `FINALLY_TOKEN` | (없음) | 앱만 부르게 하는 공유 비밀 |
| `FINALLY_MAX_BYTES` | 300MB | 내려받기 상한 → [API 계약](../../spec/common/08-14-api.md) §1.3 |

**CPU 에서 GPU 로 옮길 때 바꾸는 것은 두 줄입니다** — `FINALLY_DEVICE=cuda`,
`FINALLY_COMPUTE=float16`. 코드는 안 바뀝니다.

⚠️ **밖에 열어 둘 때는 `FINALLY_TOKEN` 을 반드시 채우세요.** 이 서비스는 넘겨받은
주소를 내려받으므로, 열어 두면 남의 심부름을 하게 됩니다.

## 계약

```
GET  /health              무엇이 붙어 있나
POST /jobs                { kind, url, mime_type?, vocabulary? } → 202 { job_id }
GET  /jobs/{job_id}       { status, percent, engine?, lines?, reason? }
```

**기다리지 않습니다.** 전사는 몇 분 걸리고 앱의 함수는 그렇게 오래 못 삽니다.
계약이 이미 폴링입니다 → [API 계약](../../spec/common/08-14-api.md) §3.2 §3.3.

**콜백이 아닌 이유 셋** — ① 폴링은 이미 계약에 있습니다 ② 콜백이면 밖에서 앱을 부르는
구멍을 뚫어야 하는데 지금은 **들어오는 구멍이 없습니다** ③ 요청이 올 때만 켜지는
방식이면 서비스가 죽었다 살아나는 사이 콜백이 유실됩니다.

**파일은 이쪽이 직접 내려받습니다.** 앱이 중계하면 함수 본문 한계에 걸립니다 —
업로드가 이미 그 이유로 브라우저에서 저장소로 직행합니다.
읽고 나면 **바로 지웁니다** — 보관은 객체 저장소가 하고 파기는 사건과 함께 일어납니다.

| 판독 · **EasyOCR + 좌표 행 복원** | [실측 11](../../docs/research/11-로컬OCR-PII인식-실측.md) R-2 — 누출 5.7% · 과차단 0 |
