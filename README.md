# FSEC — 2026 금융 AI Challenge 준비

금융보안원(FSI) 주관 **2026 금융 AI Challenge** 출전을 위한 주제 선정 작업 폴더입니다.
주제를 확정하기까지의 리서치·후보군·컨셉 스펙을 HTML 아티팩트로 하나씩 쌓고 있습니다.

> 현재 단계: **주제 미확정.** Tier 1 후보 4건에 대해 컨셉 스펙까지 나온 상태이며,
> 최종 선택은 `03-decisions/`에 ADR로 기록합니다.

## 문서 규칙

- 아티팩트는 **단일 HTML 파일**로 작성합니다(외부 CSS/JS/폰트 의존 없음).
- 파일명은 `번호-주제-문서종류.html` 형식이며, 번호는 후보군 보드의 후보 번호를 따릅니다.
- 후보 번호는 보드 기준으로 고정합니다 — 후보가 탈락해도 남은 번호를 당기지 않습니다(문서 간 참조가 깨지므로).
