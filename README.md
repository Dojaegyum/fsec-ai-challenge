# 골든30 — 2026 금융 AI Challenge

금융보안원(FSI) 주관 **2026 금융 AI Challenge** 출품작 개발 저장소입니다.

> **골든30** — 보이스피싱 피해 직후 30분, 패닉 상태의 피해자를 지급정지·신고·서면신청까지
> 한 단계씩 이끄는 데스크톱 웹 대응 에이전트. **탐지가 아니라 사후 골든타임 대응**이 각도입니다.

현재 단계: **주제 확정(→ [ADR-0001](decisions/0001-출전-주제-선정.md)), 구현 착수 전.**
기획서 v1.2에서 구현 계약을 [`spec/`](spec/)으로 추출해 둔 상태입니다.
