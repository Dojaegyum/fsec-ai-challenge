# 자동화의 경계 — 어디까지 대신해 주고, 어디서 멈추는가

> **출처** — [최종후보군 보드](../../assets/artifacts/archived/candidates/최종후보군-보드.html)
> 「법적 경계」 절. 아카이브에 있던 사실을 **계약으로 끌어올린 것**입니다
> ([CLAUDE.md](../../CLAUDE.md) 「제도·법적 경계 사실은 아직 여기가 최신」).
>
> 2026-08-20 신설. `F-08`을 「초안 생성」에서 「기재 안내」로 좁히면서
> ([ADR-037](../../decisions/037-doc-guidance-not-generation.md)) **선이 어디인지가
> 문서에 없다는 것**이 드러났습니다.

> ⚠️ **우리는 변호사가 아닙니다.** 아래는 공개된 법령·감독기관 자료를 정리한 것이고
> **법률 자문이 아닙니다.** 선에 닿는 기능을 만들 때는 이 문서로 판단을 끝내지 말고
> **사람에게 확인**하세요.

## 이 문서가 정하는 것

**이 서비스는 자동화할 수 있는 최대한을 합니다.** 그런데 「최대한」이 어디인지가
정해져 있지 않으면 두 가지가 다 일어납니다 — 할 수 있는 것을 안 하거나, **선을 넘거나.**

새 기능을 설계할 때 **여기서 대조**하세요.

## 선

```
[ 우리가 하는 것 ]                        [ 넘으면 인허가가 필요한 것 ]
──────────────────────────────────────────┼──────────────────────────────
절차를 찾아준다      (KB 인용)             │
기한을 계산한다      (코드의 규칙)          │
값을 준비한다        (슬롯 추출·확인)       │  ← 여기까지가 우리 몫
신청 경로를 준다     (링크·전화번호)        │
어디에 무엇을 적는지 알려준다               │
돌아왔는지 확인한다  (부산물 판정)          │
──────────────────────────────────────────┼──────────────────────────────
                                          │  사용자 대신 신청을 넣는다
                                          │  금융상품을 고르거나 추천한다
                                          │  개별 사건에 법률 판단을 한다
```

**「신청 경로를 준다」가 선 바로 아래입니다.** 그 앱이 비대면 신청을 지원하는지를
**우리가 보증하지 않습니다.** 경로를 주고, 안 되면 사용자가 다른 경로로 갑니다 —
`WS-visit`이 「나갔다 돌아온다」 구조인 이유이고, 돌아왔는지는
[부산물로 판정](../backend/08-14-completion-hook.md)합니다.

## 넘으면 인허가가 필요합니다

| 하려는 것 | 걸리는 것 | 근거 |
| --- | --- | --- |
| **대신 신청을 넣기** | 마이데이터(본인신용정보관리업) 허가 — 자본금 최소 5억원 등 6개 요건 | 신용정보협회 |
| **금융상품 비교·추천** | 금융상품 **중개**에 해당 → 등록·인허가 필요 | 금융위원회 |
| **개별 자문** | 금소법 자문업. **미등록 영업 시 5년 이하 징역 또는 2억원 이하 벌금** | 금융소비자 보호에 관한 법률 |
| **주민등록번호 수집** | 법령 근거 없이 처리 금지. **3천만원 이하 과태료** | 개인정보 보호법 §24조의2 |

**주민등록번호는 이미 안 받습니다** → [ADR-026](../../decisions/026-raw-upload-retention.md).

## 우리가 선 안쪽에 있는 이유

**셋 다 「이익 수수」와 「상품 판매·중개」가 구성요건입니다.**
우리는 금융상품을 팔지도 추천하지도 않고, **사기 피해자에게 자기 사건의 절차**를 안내합니다.

| 근거 | 무엇을 말하나 |
| --- | --- |
| **대법원** | **구체적 법률 판단이 없는 문서 작성 서비스는 법률사무가 아니다.** 변호사법 §109는 **이익 수수가 구성요건** |
| **금융위 「금융광고규제 가이드라인」** | 판매 과정에 적극 개입하는 「광고 주체」는 등록 필요. **판매 촉진 목적 없는 단순 정보제공은 업무광고에 해당하지 않을 수 있음** |
| **금소법** | 자문업 정의에 「**이익을 얻을 목적으로 계속적 또는 반복적인 방법으로**」 명시. 불특정 다수가 수시로 볼 수 있는 통신물을 통한 조언은 **제외** |

**그래서 「기재 안내」는 되고 「대신 제출」은 안 됩니다.**
[ADR-037](../../decisions/037-doc-guidance-not-generation.md)이 서류를 만들지 않기로 한 것은
법적 이유가 아니라 서식 미확보 때문이지만, **결과적으로 이 선과도 맞습니다.**

## 선을 넘는 것이 실제로 가능하다는 선례

| | |
| --- | --- |
| **금융위** | **마이데이터 사업자의 금리인하요구권 자동 행사** 서비스 2026-02-26 시행. 최초 1회 동의로 상시 모니터링·**자동 신청**·거절 사유 안내. 마이데이터 13개사 + 금융회사 57개사 |
| **토스** | 「금리 인하 대상 대출 한눈에 확인 → **일괄 신청** → 거절 시 **자동 재신청**」 |
| 규모 | 시행 5개월 만에 신청 **1,000만 건** 돌파, 전년 대비 약 6배 |

**한국에서 「자동 신청」이 실제로 됩니다. 다만 마이데이터 사업자 자격이 있어야 합니다.**

우리는 그 자격이 없으므로 지금 구조가 맞고, **이것을 로드맵으로 말할 수 있습니다** —
「여기까지가 지금 할 수 있는 최대이고, 그 너머는 이런 자격이 필요하다」는 것을
**아는 채로 멈춘 것**과 모르고 안 한 것은 다릅니다.

## 새 기능을 볼 때 묻는 것

1. **사용자 대신 무언가를 제출하나?** → 넘습니다
2. **여러 선택지 중 하나를 고르라고 하나?** → 중개일 수 있습니다. 「이 사건에 해당하는 절차」는 선택지가 아니라 **분기**입니다
3. **개별 사건에 법률 판단을 내리나?** → 넘습니다. **「대상인지 진단」까지**입니다 ([불변 규칙 8](../../CLAUDE.md))
4. **이익을 받고 하나?** → 위 셋의 구성요건입니다. 무상이면 선이 다른 자리에 있습니다
