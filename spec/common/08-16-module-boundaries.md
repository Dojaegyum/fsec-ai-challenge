# 모듈 경계 — 누가 무엇을 책임지고, 무엇을 절대 하지 않는가

> **정본 관계** — 이름과 층은 [모듈 명칭](08-16-module-names.md)이 정하고(33개, CI 가 코드 폴더와 대조),
> **여기는 책임과 금지**를 정합니다. 코드에서는 각 모듈 `types.ts` 머리가 이 표의 그 줄을 옮겨 적고
> 시험이 박습니다 ([RFC-001 「모듈 골격」](../../rfc/001-repo-structure.md)). 그래서 **새 모듈의 「절대 하지 않는 것」은
> 코드보다 먼저 여기에 씁니다** — 모듈을 가로질러 보는 자리가 이것뿐입니다.
>
> 2026-08-26 축소 개정. 경계 규칙 여섯·흐름도·미결 절을 걷어냈습니다 — 규칙은 `CLAUDE.md` 불변 규칙 1~8 이 정본이고,
> 모듈이 어떻게 이어지는지는 [ARCHITECTURE §4](../../ARCHITECTURE.md) 가 그립니다. 표 33행이 이 문서의 전부입니다.
> 출처였던 기획서 §1 다이어그램(4노드)은 [ADR-023](../../decisions/023-frontend-module-names.md) 로 갈라지며 의미를 잃었습니다.

**이 문서가 정하는 것** — 각 모듈이 무엇을 받아 무엇을 내놓고, **무엇을 하면 안 되는가**.
경계를 어기면 [PII 격리 경계](08-14-pii-boundary.md)나 「LLM 은 절차를 창작하지 않는다」(`CLAUDE.md` 불변 규칙 1)가 무너집니다.

**이 문서가 정하지 않는 것** — 프로세스 분리, 배포 단위, 통신 방식. 모듈은 **책임의 단위**이지 서버의 개수가 아닙니다
(물리 배치는 [ADR-028](../../decisions/028-runtime-and-module-shape.md)).

## 세 구역

```
[브라우저 · 층 C]          [서버]                        [외부]
원문 보유           ── 격리 경계 ──           토큰화 텍스트만 도달
pii-masker  ─────────►  pii-tokenizer ──────────►  LLM API
key-handler                토큰화 텍스트 + 볼트 암호문    KB (버전드 · src/kb → kb:load)
pii-restorer               감사 로그(토큰화 기준)
```

**서버·LLM 어디에도 "누구의 어떤 계좌"인지 완성된 정보가 존재하지 않는 구조**가 목표입니다.
들어올 때(`pii-tokenizer`)와 나갈 때(`chat-publisher`)가 각각 한 자리라 우회할 자리도 하나씩입니다.

## 브라우저 — 층 C (11)

층 C 는 「언제 도는가」가 아니라 「무엇을 책임지는가」로 갈립니다 → [ADR-023](../../decisions/023-frontend-module-names.md).
**브라우저가 보여주는 것은 전부 원문**입니다 — 토큰은 경계를 넘어갈 때의 형태이지 사용자가 볼 형태가 아닙니다 ([ADR-034](../../decisions/034-browser-shows-plaintext.md)).

> **구현 상태 (2026-09-03)** — `pii-masker` 의 파일 마스킹은 구현 전입니다.
>
> **`doc-filler` 는 폐기됐습니다** → [ADR-064](../../decisions/064-doc-filler-retired.md). 기재 안내
> 화면은 셸(`doc.tsx`) 소유이고, 그 행에 있던 금지(완성 문서 수신 · 조판 문서 다운로드,

> `pii-restorer` 는 코드가 아직 [ADR-034](../../decisions/034-browser-shows-plaintext.md) 이전의 부분 복원을 따릅니다 —

## 이 표를 고칠 때

- **새 모듈** — 이름을 [모듈 명칭](08-16-module-names.md)에 먼저 올리고, 여기 한 줄을 쓴 뒤, `types.ts` 머리에 그 줄을 옮겨 적고 금지를 시험으로 박습니다.
- **금지를 바꿀 때** — 여기와 `types.ts` 를 같은 커밋에서 고칩니다. 둘이 어긋나면 이 표가 이깁니다 — 다만 시험이 코드 쪽을 지키고 있으니, 어긋남을 발견하면 어느 쪽이 나중 결정인지 ADR 로 확인한 뒤 맞춥니다.
- **경계를 넘는 규칙**(토큰화 우회 금지 · 키는 브라우저에만 · 날짜는 규칙 · 모름은 정상 경로)은 여기 되풀이하지 않습니다 — `CLAUDE.md` 불변 규칙이 정본입니다.
