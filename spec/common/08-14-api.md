## 기획서에서 이미 정해진 제약

API를 설계할 때 지켜야 하는 것들입니다. 이건 정해져 있습니다.

- **PII 경계** — 외부 LLM으로 나가는 페이로드는 토큰화된 텍스트만. 스크러버를 우회하는 경로를 만들 수 없습니다 → [04](08-14-pii-boundary.md)
- **복원 매핑은 서버에 저장하지 않음** — 서버 API는 토큰만 다룹니다
- **세션 격리 · TTL 24h** — 사건 스토어의 수명
- **감사 로그** — 모든 LLM 호출 기록 (토큰화 텍스트 기준)
- **KB 인용 강제** — 플랜 생성 응답은 근거·시행일을 함께 반환해야 합니다 → [07](../backend/08-14-kb-operations.md)

## 서버 구성 요소

각 모듈의 책임·입출력·금지는 [모듈 경계](08-16-module-boundaries.md)로 옮겼습니다.
엔드포인트를 설계하기 전에 그 문서와 [도메인 모델](08-16-domain-model.md)을 먼저 읽으세요 —
**무엇을 주고받는지가 정해져야 어떻게 주고받을지를 정할 수 있습니다.**
