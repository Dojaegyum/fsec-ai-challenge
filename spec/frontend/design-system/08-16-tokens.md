## 초안에서 확정된 것

### 표면 사다리 — 어디에 놓인 것인가

깊이를 색으로 구분합니다. 테두리 대신 **표면 밝기와 inset 하이라이트**로 층을 만듭니다.

| 토큰 | 뜻 | 쓰이는 곳 |
| --- | --- | --- |
| `--color-ground` | 페이지 바닥 | 랜딩 배경 |
| `--color-stage` | 작업이 일어나는 무대 | 챗 콘솔 영역 |
| `--color-surface` | 떠 있는 카드 | 사건 보드, 입력 카드 |
| `--color-hairline` | 표면끼리 맞닿는 경계 | 카드 테두리, 셀 구분선 |
| `--color-chip` | 눌러지거나 상태를 나타내는 알약 | 배지, 선택 버튼, 입력 필드 |

**칩은 배경색이 아니라 반투명 흰색 + inset 하이라이트입니다.** 어느 표면 위에 얹혀도 같은 재질로 보이게 하려는 것이라, 불투명 색으로 바꾸지 마세요.

### 텍스트 사다리 — 얼마나 중요한가

| 토큰 | 뜻 | 쓰이는 곳 |
| --- | --- | --- |
| `--color-ink-1` | 사용자가 반드시 읽어야 하는 것 | 헤드라인, 금액, 기한 숫자 |
| `--color-ink-2` | 본문 | 단계 설명, 칩 라벨 |
| `--color-ink-3` | 보조 설명 | 부연, 힌트 |
| `--color-ink-4` | 가장 약한 것 | placeholder, 비활성 |
| `--color-icon` | 아이콘 선 | 입력창 아이콘 |

> ⚠️ **`--color-ink-4`는 대비 기준에 미달합니다**(2.03:1). 읽어야 하는 문장에 쓰지 마세요 —
> 자세한 것은 [접근성](08-16-accessibility.md)에 실측표가 있습니다.

### 상태 색 — 무엇을 뜻하는가

| 토큰 | 뜻 | 쓰이는 곳 | 상태 |
| --- | --- | --- | --- |
| `--color-pii` | **가려진 개인정보.** 이 색이 보이면 "서버로 안 갔다"는 뜻 | 전사 뷰 토큰, 토큰화 배지 | 확정 |
| `--color-pii-bg` | 위의 배경 | 토큰 칩 | 확정 |
| `--color-deadline-urgent` | **법정 기한 임박.** 놓치면 권리가 사라지는 것 | D-day, 3영업일 경고 | 확정 |
| `--color-horizon` | 브랜드 분위기(장식). **의미를 싣지 마세요** | 히어로 글로우 | 확정 |
| `--color-risk-high/mid/low` | 수법 위험도 (F-04) | 분석 결과 | TODO |

**빨강을 쓰지 않기로 했습니다.** 기한 임박은 앰버(`--color-deadline-urgent`)입니다.
사용자는 방금 사기를 당해 이미 각성 상태이고, 빨간 경보를 더하면 판단을 돕는 게 아니라 굳게 만듭니다.
빨강은 `--destructive`(파괴적 동작 확인)에만 남겨 둡니다.

**완료·미확인에는 전용 색을 만들지 않았습니다.** `--color-verified`·`--color-unknown` 대신
중립 칩 + 텍스트 사다리로 구분합니다 — 색이 하나 늘 때마다 뜻을 외워야 할 것이 늘기 때문입니다.
색만으로 구분하지 않는다는 원칙([접근성](08-16-accessibility.md))에도 이쪽이 맞습니다.

## 타이포

| 결정 | 내용 |
| --- | --- |
| 한국어 줄바꿈 | **`word-break: keep-all` 필수.** 없으면 "동/행합니다"처럼 어절이 쪼개집니다 |
| 넘침 처리 | `overflow-wrap: break-word`를 함께 걸어 긴 URL·계좌번호가 레이아웃을 밀지 않게 |
| 제목 균형 | `text-wrap: balance` |
| 숫자·기한 | **`font-variant-numeric: tabular-nums`.** 기한 숫자가 자리마다 흔들리면 오독합니다 |
| 폭 제한 | 한글은 `ch` 단위가 라틴 기준이라 좁게 잡힙니다. 본문 `54ch`, 제목 `26ch`가 초안 기준 |
