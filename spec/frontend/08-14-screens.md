## 폐기된 화면 — 번호는 재사용하지 않습니다

**S-01·S-02는 폐기됐고 번호를 다시 쓰지 않습니다.** 새 화면은 S-04부터입니다.

| 옛 화면 | 무엇이었나 | 지금은 어디 |
| --- | --- | --- |
| `S-01` 사건 생성 `/case/new` | 업로드가 첫 화면. 3-패널 | **전제가 사라졌습니다.** 첫 화면은 랜딩([S-04](#s-04--랜딩--))이고, 업로드는 [S-05](#s-05--동의--선택-제공--start)의 **선택 항목**·[S-08](#s-08--증거함--ctoken)입니다 |
| `S-02` 대응 플랜 `/case/{id}/plan` | 3-패널 플랜 화면 | [S-07 보드 국면](#s-07--사건--보드-국면--ctoken) · [S-09 단계 상세](#s-09--단계-상세--부산물--ctokenstepid) |

`S-03` 피싱 백신은 그대로입니다 — 3-패널과 무관하고 전제도 안 바뀌었습니다.

**무엇을 보여주는 상태인가**입니다. 셋 사이의 이동은 내비게이션이 아니라 **국면 전환**이고,
`case-opener`가 링크를 열 때 어느 상태로 들어갈지 정합니다 →
[모듈 명칭](../common/08-16-module-names.md) 층 C.

/vaccine              피싱 백신 (부가)

## S-04 · 랜딩 — `/`

**검색으로 온 사람에게 「여기는 신고 다음을 맡는 곳」이라는 것 하나를 이해시킵니다.**
설명을 늘리면 실패합니다 — 진입은 검색·직접 접속이 전제입니다
([ADR-021](../../decisions/021-reentry-and-identity.md)).

| | |
| --- | --- |
| 행동 | **[지금 시작하기] 하나.** 스크롤 아래에도 두 번째 행동을 두지 않습니다 |
| 폭 | **셸 폭**(`--container-shell`). 랜딩만 예외이고, 국면 1 이후는 좁은 폭입니다 |
| 첫 화면 | 스크롤 없이 보이는 곳에서 **3초 안에** 납득시킵니다. 아래는 그다음 몫입니다 |
| 금지 | 기능 목록·메뉴·앵커 내비게이션·요금 링크 |

### 스크롤 네 마디 (→ [ADR-028](../../decisions/028-scroll-landing.md))

**스크롤은 허용하되, 아래로 갈수록 요구가 줄어야 합니다.** 읽어야 이해되는 것을
아래에 쌓으면 「읽어야 하는 페이지」가 되고, 패닉 상태에서는 안 읽힙니다.

| 마디 | 무엇 | 계약 |
| --- | --- | --- |
| ① 히어로 | 심볼 · 헤드라인 · 서브카피 · **[지금 시작하기]** | 스크롤 없이 **여기까지가 보입니다.** 행동이 접히면 안 됩니다 |
| ② 하는 일 셋 | 진술→절차 · 기한 계산 · 서류 | 훑고 지나가도 「뭘 해주는지」가 남아야 합니다 |
| ③ 화면 소개 | `/start` · 챗 · 보드 · 증거함·서류 | **보여주는 것**이지 읽히는 것이 아닙니다 — 미니 목업 + **한 줄** |
| ④ 고지 | **112 우선** · 환급 비보장 | 페이지 끝에 한 줄. 문구를 줄이지 않습니다 |

**③은 기능 목록이 아닙니다.** 화면 넷이 각각 무엇을 하는 자리인지를 그림으로 보여주는
것이고, 각 화면당 설명은 **한 줄을 넘기지 않습니다.** 항목이 늘어나거나 줄글이 붙으면
그 순간 금지된 「기능 목록」이 됩니다.

**④의 112 안내는 뺄 수 없습니다.** 전환율을 깎는 자리지만, 빼면 아직 신고 전인 사람을
우리 화면에 붙잡습니다. ①에 두면 첫 화면이 두 갈래가 되므로 **끝에 둡니다** —
스크롤이 생기면서 이 자리가 생겼습니다.

**히어로의 장식(오비트 링·글로우)은 뜻을 싣지 않습니다.** `--horizon` 규칙 그대로이고
전부 `aria-hidden`입니다. 회전은 `prefers-reduced-motion`이 멈춥니다
([design-system/08-16-tokens.md](design-system/08-16-tokens.md)).

## S-05 · 동의 · 선택 제공 — `/start`

**관문은 동의 하나뿐입니다.** 동의는 법적 필수라 관문이지만,
**증거와 기본 정보는 줄 수 있는 사람만 줍니다** — 폼을 통과해야 다음으로 가는 구조를 만들면
「모름은 실패가 아니다」 위반입니다 ([02-slot-tiering.md](../backend/08-14-slot-tiering.md)).

| | |
| --- | --- |
| 관문 | **동의만.** 「건너뛰고 바로 시작」이 **같은 화면**에 있습니다 |
| 이메일 | **선택.** 안 주면 알림이 없고 일회성으로 끝난다는 것을 **같은 크기로 옆에** 씁니다 |
| 증거 | 선택. 올리면 `pii-masker`가 브라우저에서 가린 뒤 `file-sender`가 보냅니다 |
| API | `POST /api/cases` ([08-api.md](../common/08-14-api.md) §3.1) · `POST …/evidence` §3.2 |

**링크 발급은 되돌릴 수 없는 갈림길입니다.** 발급 즉시 **복사할 수 있어야** 하고,
잃으면 복구 경로가 없다는 것을 그 자리에서 알립니다 — 계정이 없어 되찾아 줄 방법이 없습니다.

> ⚠️ **동의 문구가 아직 「24시간 후 파기」입니다.** [ADR-016](../../decisions/016-retention-and-datastore.md)의
> **180일**로 고쳐야 하고, 「주민등록번호를 수집하지 않는다」도 들어가야 합니다
> ([ADR-026](../../decisions/026-raw-upload-retention.md)).

## S-06 · 사건 · 챗 국면 — `/c/{token}`

**진술을 받아 가장 적절한 매뉴얼을 고르는, 이 서비스의 핵심 동작입니다.**

| | |
| --- | --- |
| 규칙 | 질문은 **한 번에 하나 · 전부 버튼 · 「모름」 상시** (`F-05b`) |
| T0 | 안전 절차는 **슬롯과 무관하게 상시** 붙어 있습니다 |
| API | `POST …/messages` §3.9 · `GET …/slots` §3.4 |
| 금지 | **응답을 스트리밍하지 않습니다.** 근거 검증(`citation-checker`)이 끝난 뒤 한 번에 나갑니다 |

**답변의 토큰은 종류별로 부분 복원됩니다** — 브라우저의 `pii-restorer`가 합니다
([ADR-013](../../decisions/013-chat-context.md)).

## S-07 · 사건 · 보드 국면 — `/c/{token}`

**며칠 뒤 링크를 열었을 때 「지금 뭘 해야 하나」가 첫 줄이어야 합니다.**
빈 챗창이 뜨면 관리 서비스가 아닙니다.

| | |
| --- | --- |
| 무엇 | 단계 · 기한 · 진행 타임라인 |
| API | `GET …/plan` §3.6 · `GET …/deadlines` §3.7 |
| 기한 | **서버가 계산한 값만 표시합니다. 화면은 날짜를 세지 않습니다** ([10-deadline-rules.md](../common/08-16-deadline-rules.md)) |
| 색 | 기한 임박은 **앰버**. **빨강을 쓰지 않습니다** — 패닉 상태를 더 밀어붙이지 않습니다 |

**할 일이 없는 국면에도 보드는 빕니다 하지 않습니다.** 채권소멸 공고 2개월 구간에도
**사용자 기한이 둘 살아 있습니다**(1만원 이하 통지 후 30일, 공고 후 2개월) →
[research/06](../../docs/research/06-경로별-실측조사.md). 그 자리의 일은 **통지 해독**입니다.

## S-08 · 증거함 — `/c/{token}`

**전사가 흐르고 PII가 파란 토큰으로 바뀌는 것이 눈에 보이는 자리입니다.**
「AI가 뭘 하고 있는지 투명한 것」 자체가 심사 차별점입니다.

| | |
| --- | --- |
| 상태 | `pending` · `processing` · `done` · `failed` |
| API | `POST …/evidence` §3.2 · `GET …/evidence/{id}` §3.3 |
| 의미 | **파란 토큰 = 「서버로 안 갔다」.** 이 대응을 화면에서 흐리지 마세요 |
| 금지 | 업로드를 관문으로 만드는 것. 증거가 없어도 T0는 그대로 돕니다 |

**주민등록번호가 든 파일은 올라가지 않습니다.** `pii-masker`가 가리지 못하면
**그 파일만 빼고 진행**합니다 — 막는 것이 아니라 갈림길입니다
([ADR-026](../../decisions/026-raw-upload-retention.md)).

## S-09 · 단계 상세 · 부산물 — `/c/{token}/step/{id}`

**완료가 판정되는 유일한 자리입니다.**
[워크스페이스 패널 `WS-*` 일곱](08-17-workspace-panels.md)이 여기 붙고,
어느 유형을 열지는 서버의 `body.action`이 정합니다 ([ADR-024](../../decisions/024-step-action-and-url.md)).

| | |
| --- | --- |
| 상태 | 미시작 · 진행중 · **완료(증빙됨)** · **미확인** · 건너뜀 |
| API | `POST …/steps/{id}/artifacts` §3.8 |
| 핵심 장치 | 통화 종료 직후 **「접수번호를 지금 받아적으세요」**가 뜨는 것 — 타이머가 도는 동안 입력칸이 **이미** 떠 있어야 합니다 |
| 금지 | **체크만으로 완료가 되는 경로** ([05-completion-hook.md](../backend/08-14-completion-hook.md)) |

## S-10 · 서류 초안 — `/c/{token}/doc/{id}` (P1)

피해구제신청서·자율배상 신청 초안. **내려받을 때 PII가 브라우저에서만 복원됩니다.**

| | |
| --- | --- |
| 누가 | `doc-filler` — 값을 채우는 것은 브라우저입니다 |
| 금지 | **서버가 완성 문서를 내려주는 구조** ([04-pii-boundary.md](../common/08-14-pii-boundary.md) 규칙 6) |
| 기대치 | 자율배상은 **대상인지 진단해주는 것**까지입니다. 「받을 수 있다」고 쓰지 않습니다 |

## S-03 · 피싱 백신 — `/vaccine` (F-09, 부가)

평시 훈련 모드. 가족 등록·동의 상태, 훈련 결과와 취약 패턴, 가족 안전 리포트.

- 동의는 **미리** 받되 시점은 **예고 없이** (향후 2주 내 무작위)
- 목표는 "속이기"가 아니라 **대응 리허설** — 끊기 → 공식번호 확인 → 절차 말하기
- 훈련 종료 즉시 **"훈련이었습니다" 해제 고지** 필수
- 발신은 사전 동의된 **웹 링크 기반 — 실제 전화망 미사용**
- 훈련 데이터는 가족 계정에만 보관

## 화면 전반 원칙

- 사용자는 **패닉 상태**입니다. 한 화면에서 요구하는 판단을 최소화합니다.
- 질문은 **한 번에 하나, 전부 버튼**으로 (`F-05b`). **「모름」 선택지가 상시 존재**합니다.
- 미확정 정보는 숨기지 말고 **「미확인」 배지**로 드러냅니다.
- 파이프라인의 각 단계가 **눈에 보이게** 합니다 — 숨기지 않는 것이 신뢰 장치입니다.
- **기한을 화면에서 세지 않습니다.** 서버가 계산한 값을 그대로 표시합니다.

### 화면마다 「폰용」·「데스크톱용」을 정하지 않습니다

**반응형 하나입니다.** 제출물이 배포 주소라 심사위원이 임의 기기로 엽니다.
국면별 **좁은 폭 / 넓은 폭**은 「그 시점에 그 폭에서 열릴 가능성이 높다」는 뜻이지,
**그 폭에서만 동작한다는 뜻이 아닙니다.**
